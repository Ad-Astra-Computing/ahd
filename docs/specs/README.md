# Specs

A short design spec precedes any non-trivial change. It states the
problem, the intended behavior and the acceptance criteria before code.

Copy `template.md` to `NNNN-short-title.md`, starting at `0001`. Keep it
to about a page. A spec that grows past that is a sign the work should be
split. The acceptance criteria map to tests, so a feature is done when
each criterion has a passing test.

See `STANDARD/02-development-method.md` in the Ad Astra project
skeleton checkout; it is not part of this repo.
