the slop is real. ai-generated interfaces lack structure, taste, and constraint. ahd is a framework to enforce design logic on stochastic outputs. we provide the scaffold; you provide the models.

  • vision-critic scaffold

  • eight tokens

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
