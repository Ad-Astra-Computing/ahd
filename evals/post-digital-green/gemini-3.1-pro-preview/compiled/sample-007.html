artificial human design

a framework to enforce taste in generated interfaces. if you are reading this, you already know the problem: the default output of frontier models is generic, rounded, and gradient-soaked. prompt engineering alone cannot override the reinforcement learning.

ahd imposes deterministic constraints on non-deterministic systems. it lints out the slop.

  • eval harness
  • vision-critic scaffold
  • mcp server

  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
