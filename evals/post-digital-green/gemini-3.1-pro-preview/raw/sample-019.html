Artificial Human Design

AHD Framework

You have seen the generated interfaces over the last month. The layouts are converging, the structures are predictable and the design intent is completely absent. We do not need to explain the problem with this output.

AHD provides an evaluation harness and a deterministic framework. It takes design constraints seriously and enforces them programmatically. Stop prompting for aesthetics and start writing tests for them.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • Brief compiler
  • 28-rule linter
  • Eval harness
  • Vision-critic scaffold
  • MCP server
  • Editor plugins
  • Eight tokens

What is gated

  • Live frontier-model calls (needs API keys)
  • Live vision critique (needs multimodal key + screenshot pipeline)
  • Standalone npm packages for the editor plugins
  • Additional tokens
