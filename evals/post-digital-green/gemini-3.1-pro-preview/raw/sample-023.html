Artificial Human Design

You already see the pattern. The latent space defaults to a generic monoculture of interfaces. AHD is an intervention.

We provide a strict evaluation framework designed to force generation pipelines into typographic and structural discipline. We apply declarative constraints prior to generation and execute automated visual critiques on the render.

This is a harness to systemise intentional design and prevent regression to the mean.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
