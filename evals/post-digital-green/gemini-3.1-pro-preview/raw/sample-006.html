Artificial Human Design

The generative output problem is structural. The models do not lack capability; they suffer from regression to the mean. Without rigorous constraints, generated interfaces devolve into a homogenous layer of visual noise. You already know the markers: meaningless soft shadows, floating tiles and default spacing systems.

AHD provides a deterministic framework to enforce architectural and aesthetic parameters on generated output. It replaces stochastic prompting with an evaluation harness, a compiler and a strict rule linter. If you need a systemic baseline rather than an endless conversation, this is the architecture.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
