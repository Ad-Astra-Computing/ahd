Artificial Human Design

A framework for structural intent

The output is regressing to the mean. The current cycle of generated interfaces proves the underlying models can assemble components but cannot exercise care. They rely on statistical averages and produce indistinguishable slop. You do not need another thesis on why this is happening. You need a mechanism to enforce intent.

AHD is a rigid evaluation harness for interface generation. It demands structure over decoration. It tests layouts against a hard set of rules to separate deliberate design choices from hallucinatory noise. This is a tool for enforcement rather than a lecture on aesthetics.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
