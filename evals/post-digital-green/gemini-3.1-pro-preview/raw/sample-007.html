Artificial Human Design

The web is saturated with generated outputs. You already recognise the symptoms: identical layouts, arbitrary aesthetics and structural incoherence. We do not need another lecture on the problem.

AHD is a framework to evaluate and enforce strict design intent over generated markup. It replaces subjective frustration with a continuous integration pipeline for taste.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
