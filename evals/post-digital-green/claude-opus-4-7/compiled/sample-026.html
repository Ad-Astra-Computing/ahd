ahd / artificial human design v0.1.0
2026-04-24 █

design, evaluated against itself.

ahd is a framework for generating and grading interface work with the same rigour you'd grade a compiler. briefs are compiled. tokens are typed. output is linted, rendered, and critiqued. the slop problem is not the thesis; it is the test case.

the one-liner
bash
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

runs the compiled brief against n=10 variants per model, lints each against 28 rules, screenshots, and scores with the vision critic.

pipeline
  brief.yml  ──▶  [compile]  ──▶  spec.json  ──▶  [generate]  ──▶  html
                     │                                │

                                ▼
                          [render + shot]  ──▶  png
                                │
                                ▼
                         [vision critic]  ──▶  score + notes

what ships

  • brief compiler — yaml → typed spec
  • 28-rule linter — tokens, grid, forbidden-patterns
  • eval harness — n-of-k, diff, rank
  • vision-critic scaffold — prompts, rubric, cache
  • mcp server — for editor and agent clients
  • editor plugins — vscode, zed (in-tree)
  • eight tokens — including post-digital-green

what is gated

  • live frontier-model calls — needs api keys
  • live vision critique — multimodal key + shot pipeline
  • standalone npm packages for the editor plugins
  • additional tokens — roadmap, not vapourware
