  <section><!-- rule: no centred hero stack with pill + two CTAs -->
    <span class="section-label">00 — premise</span>
    <h1>a design framework for people who have already<br>noticed the slop.</h1>
    <p class="dim" style="margin-top:8px">
      ahd treats machine-authored interfaces as a measurable output.
      a brief compiles to constraints. constraints compile to a linter.
      the linter feeds an eval harness. the harness scores n generations
      from m models against the brief. nothing here is a lecture; it is
      a loop you can run.
    </p>
    <p style="margin-top:12px">
      <a href="https://github.com/ahd/ahd">read the code on github &rarr;</a>
      <span class="dim"> // mirror: </span>
      <a href="https://forge.ahd.dev/ahd/ahd">forgejo</a>
    </p>
  </section>
