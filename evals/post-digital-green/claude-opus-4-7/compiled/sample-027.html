you already know the shape of the problem. every landing page this month looks like the same four cards under the same purple hero. ahd is not a lecture about that. it is a compiler, a linter, an eval harness, and a set of tokens that refuse to produce it.

one brief in. n variants out. each variant linted against 28 rules and graded by a vision critic that can actually see the page. the amber is the only accent you will see here, and it is here on purpose.

run the eval

one line. ten renders. no ceremony.

# bash
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10 

pipeline

  brief.yml
     |
     v
  [ compiler ] ---> compiled prompt (token + rules + forbiddens)
     |
     v
  [ n models ] ---> n candidate pages
     |
     v
  [ 28-rule linter ] --fail--> reject + diff
     |  pass
     v
  [ vision critic ]  ---> score, notes, screenshot
     |
     v
  artefact/  (html, png, json, trace)
