a framework, not a lecture

you have seen the output. thin gradients, three equal cards, a pill badge between two buttons. ahd treats that as a measurable failure mode and ships the tools to prevent it: compiled briefs, a linter that refuses the known regressions, and an eval harness that scores real renders against a token's forbidden list.

no testimonials. no pricing tier. read the code, run the eval, read the diff.

pipeline

  brief.yml ──▶ [compiler] ──▶ prompt ──▶ [model] ──▶ render
                   │                                     │
                   ▼                                     ▼
              token.json                            [28-rule linter]
                   │                                     │
                   └────────────────┬────────────────────┘
                                    ▼
                              [eval harness] ──▶ score + diff
                                    │
                                    ▼
                           [vision-critic scaffold]

run the eval

bash$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

ten renders per model, linted, scored, diffed against the token. failing artefacts are kept; they are the point.
