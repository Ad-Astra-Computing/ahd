ahd / artificial human design
github forgejo

a framework for design that is not slop.

you have seen the sites. purple-to-blue hero, three equal feature cards, a pill badge, two buttons, a corporate memphis girl holding a laptop. the problem is not that a model made it. the problem is that nothing constrained it. ahd is the constraint layer: a brief compiler, a linter, and an eval harness that treats design as something you can fail.

pipeline

brief.yml ──► [compile] ──► token + rules ──► [generate] │ ▼ candidate.html │ ┌────────────────────────┼────────────────────────┐ ▼ ▼ ▼ [28-rule lint] [vision critic] [eval harness] │ │ │ └──────────────► score ◄─┴──────────────► rank / diff

run the eval

one brief, n candidates, k models, a linter and a vision critic. the harness returns a ranked manifest and a diff against the spec. 

# bash
$ ahd eval-live swiss-editorial \
      --brief briefs/landing.yml \
      --models <specs> \
      --n 10

see the read-the-code CTA for the full flag surface, exit codes, and fixtures.

what ships — today, in-repo, no key required

core

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold

surface

  • mcp server
  • editor plugins
  • eight tokens
  • cli & fixtures

what is gated — needs external resources

  • live frontier-model calls  — needs api keys
  • live vision critique  — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins
  • additional tokens

the scaffold runs offline against recorded traces. to run eval-live you bring your own keys; ahd does not proxy them.
