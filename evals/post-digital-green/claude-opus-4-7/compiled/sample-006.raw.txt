  <section style="margin-top:16px;">
    <!-- rule: terse, lowercase, technical voice -->
    <p>
      ahd is a brief compiler, a linter, and an eval harness. you write a brief
      in yaml. ahd compiles it into a token spec plus a forbidden list. a model
      generates html. the linter and a vision critic score the output against
      the spec. nothing here is a lecture about taste; it is a feedback loop.
    </p>
  </section>

  <!-- rule: at least one ASCII diagram rendered as text -->
  <section style="margin-top:16px;" aria-label="pipeline diagram">
    <div class="caps">pipeline</div>
    <pre class="ascii box" aria-hidden="true">
   brief.yml ──▶ [ compile ] ──▶ spec.json ──▶ [ model ] ──▶ page.html
                     │                                          │
                     ▼                                          ▼
                [ 28-rule linter ] ◀──── render ────▶ [ vision-critic ]
                     │                                          │
                     └────────────▶ score ◀─────────────────────┘
    </pre>
  </section>

  <!-- rule: terminal-aesthetic one-liner code block, language tag bash -->
  <section style="margin-top:16px;">
    <div class="caps">run the eval</div>
    <pre class="bash" aria-label="eval command"><code>ahd <span class="amber">eval-live</span> swiss-editorial \
  --brief briefs/landing.yml \
  --models &lt;specs&gt; \
  --n 10</code></pre>
    <p class="dim" style="margin-top:8px;">
      ten generations per model, scored deterministically by the linter and
      qualitatively by the critic. results land in <code>./runs/</code> as
      flat html plus a single <code>index.json</code>.
    </p>
  </section>
