design that fails the eval is slop.
ahd writes the eval.

you have already seen the pattern this month: centred hero, pill badge, two CTAs, purple-to-blue on the word ai, three equal cards, a trust bar of logos nobody verified. the thesis is not the interesting part. what is interesting is a framework that catches it before a human has to.

ahd is a brief compiler, a linter, and a live eval harness. it compiles a token + brief into a prompt that forbids specific visual clichés, runs n frontier models against it, and scores the outputs against 28 hairline rules. the cli one-liner is the whole pitch_

~/ahd bash 
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

output: one html per model, one lint report per html, one vision critique per render, one aggregate score. artefacts land in ./runs/<ts>/.
