ahd // artificial human design v0.1.0 · 2026-04-24

a framework against design slop. 

you have seen the output. pastel gradients, lucide icons in glass tiles, three equal feature cards, a purple hero. ahd is a linter, a brief compiler, and an eval harness that treats generated design as code and refuses the defaults.

read the code on github  /  forgejo mirror

one-liner · eval

#!/usr/bin/env bash
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

compiles the brief, renders n candidates against the named token, scores each with the 28-rule linter, optionally forwards screenshots to a vision critic, writes a deterministic report.

position

the slop thesis is not the product. the product is the machinery that makes taking it seriously cheap: a compiler that turns intent into a token-bound spec, a linter that enforces forbidden patterns, a harness that runs the same brief across models and reports the deltas.

no testimonials. no pricing tier. no trusted-by strip. the repository is the argument.
