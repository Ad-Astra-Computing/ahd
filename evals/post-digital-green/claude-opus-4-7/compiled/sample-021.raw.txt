    <h1>artificial human design<span class="caret">&nbsp;</span></h1>
    <p class="dim">a framework for designing with models without letting the models design for you.</p>

    <p>you have seen the output. rounded corners, purple-to-blue hero, three
    equal feature cards, a pill badge above two cta buttons, a trusted-by
    logo bar, a shimmer on the word ai. you already know the problem. ahd
    is the other side of that: a brief compiler, a linter, and an eval
    harness that treats taste as testable.</p>

    <p>
      <!-- rule: read-the-code CTA labelled explicitly -->
      <a href="https://github.com/ahd/ahd" rel="noopener">read the code &rarr; github.com/ahd/ahd</a>

  <section>
    <h2>the one-liner</h2>
    <p>point it at a brief and a set of model specs. it generates, lints,
    critiques, scores. ten seeds, deterministic where possible.</p>
<!-- rule: terminal-aesthetic code block with language tag bash -->
<pre data-lang="bash"><span class="tag">[bash]</span>
<span class="prompt">$</span> ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models &lt;specs&gt; \
    --n 10</pre>
  </section>

    <section>
      <h2>what ships</h2>
      <ul>
        <li>brief compiler &mdash; yaml &rarr; prompt + constraint set</li>
        <li>28-rule linter &mdash; static checks on generated html/css</li>
        <li>eval harness &mdash; n-seed runs, diff, score, persist</li>
        <li>vision-critic scaffold &mdash; interface + local stub critic</li>
        <li>mcp server &mdash; brief, lint, eval exposed as tools</li>
        <li>editor plugins &mdash; vscode, zed, neovim (in-repo)</li>
        <li>eight tokens &mdash; post-digital-green, swiss-editorial,
            brutalist-print, terminal-amber, grid-notebook,
            mono-oxford, anti-corp-zine, and this one</li>
      </ul>
    </section>
    <section>
      <h2>what is gated</h2>
      <ul>
        <li>live frontier-model calls &mdash; requires your own api keys</li>
        <li>live vision critique &mdash; requires a multimodal key and a
            working screenshot pipeline (playwright or equivalent)</li>
        <li>standalone npm packages for the editor plugins &mdash;
            currently vendored, not yet published</li>
        <li>additional tokens &mdash; queued; shipped as contributions land</li>
      </ul>
    </section>
  </div>

  <section>
    <h2>posture</h2>
    <p>ahd is not a generator you point at a blank page. it is a contract
    between a human with a point of view and a model that will happily
    regress to the mean. the brief is the contract. the linter enforces
    it. the eval tells you whether the model obeyed it this time.</p>
    <p class="dim">if a design decision cannot be cited against a rule in
    the brief, it is a bug.</p>
