ahd / artificial human design
v0.1.0  ·  2026-04-24

design slop is a measurable defect. 

you have seen the sites. purple-to-blue hero, three feature cards, a trusted-by strip, a pill badge above two buttons. the models learned the median and served it back. ahd is a framework that treats that median as a regression and writes tests against it.

briefs compile to constraint tokens. tokens feed a 28-rule linter and a vision critic. an eval harness runs the same brief across frontier models and scores the output against the token. the loop is the product.

 brief.yml ──▶ compiler ──▶ token.json ──┐
                                          │
                                          ▼
                                    linter (28)
                                          │
                        ┌─────────────────┼─────────────────┐
                        ▼                 ▼                 ▼
                   eval harness   vision critic     mcp server
                        │                 │                 │
                        └────────── score ─┴──── editor ◀───┘

run the eval

one brief, n runs per model, scored against the token. the command is the spec. 

$ # bash
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10
