  <section>
    <p>
      ahd is a brief-driven framework for evaluating and constraining
      generated interfaces. it assumes you have already noticed that
      most model output regresses to a single visual mean. it does not
      argue the point.<span class="caret">&nbsp;</span>
    </p>
    <p style="margin-top:12px;">
      the system compiles a brief into hard constraints, lints the
      output against 28 rules, and re-runs the same brief across n
      models so the regression is visible rather than ambient.
    </p>
  </section>

  <hr>

  <!-- rule: required ASCII diagram, rendered as text -->
  <section>

  +-----------+   +-----------+   +-----------+   +-----------+
                                                        |
                        +-------------------+           v
                        |  vision-critic    |&lt;----+-----------+
                        |  (scaffold)       |     |  linter   |
                        +-------------------+     |  28 rules |
                                                  +-----------+
    </pre>
