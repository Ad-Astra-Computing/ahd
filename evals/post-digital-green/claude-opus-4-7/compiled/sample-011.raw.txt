    <h1>design that is not<br>autocompleted.</h1>
    <p class="mt-16 dim">
      ahd is a framework for designing with language models without
      letting them drift to the mean. it compiles a brief, lints the
      output against 28 rules, runs an eval across model specs, and
      asks a vision-critic whether the result looks like the brief or
      looks like every other generated page you have seen this month.
    </p>
    <p class="mt-16">
      <!-- rule: link underline-offset 4px, no colour change -->
      <a href="https://github.com/ahd/ahd">read the code &rarr; github.com/ahd/ahd</a>
      &nbsp;&nbsp;
      <span class="dim">mirror:</span>
      <a href="https://forge.ahd.dev/ahd/ahd">forge.ahd.dev/ahd/ahd</a>
    </p>
  </section>

  <!-- rule: terminal-aesthetic code block with bash language tag -->
  <section class="mt-32">
    <div class="bar">
      <h2>the one-liner</h2>
      <span class="caps t-1 dim">lang: bash</span>
    </div>
    <pre class="mt-12" aria-label="bash"><code><span class="prompt">$</span> <span class="cmd">ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10</span><span class="caret">&nbsp;</span></code></pre>
    <p class="mt-8 dim t-1">
      runs the brief through n=10 samples per model spec, lints each
      artefact, asks the vision critic, emits a scorecard to stdout.
    </p>
  </section>

  <!-- rule: at least one ASCII diagram rendered as text -->
  <section class="mt-32">
    <h2>pipeline</h2>
    <pre class="ascii mt-12" aria-hidden="false">

      │
      ▼
  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
  │ brief        │───▶│ model spec   │───▶│ artefact     │
  │ compiler     │    │ (n samples)  │    │ (html/css)   │
  └──────────────┘    └──────────────┘    └──────┬───────┘
                                                 │
                          ┌──────────────┐       │
                          │ 28-rule      │◀──────┤
                          │ linter       │       │
                          └──────┬───────┘       │

                                 ▼               ▼
                          ┌──────────────────────────────┐
                          │ scorecard  ·  diff  ·  stdout│
                          └──────────────────────────────┘
    </pre>

        <h2>what ships</h2>
        <p class="dim t-1 mt-4">in the repo, today, no keys required.</p>
        <ul class="manifest mt-12">
          <li><span class="tag">compiler</span><span>brief compiler &mdash; yaml in, typed spec out.</span></li>
          <li><span class="tag">linter</span><span>28-rule linter &mdash; structural + token checks.</span></li>
          <li><span class="tag">harness</span><span>eval harness &mdash; n-sample runs, diffing, scorecards.</span></li>
          <li><span class="tag">critic</span><span>vision-critic scaffold &mdash; rubric, prompts, wiring.</span></li>
          <li><span class="tag">mcp</span><span>mcp server &mdash; brief/lint/eval tools over stdio.</span></li>
          <li><span class="tag">plugins</span><span>editor plugins &mdash; vscode + zed, bundled in-tree.</span></li>
          <li><span class="tag">tokens</span><span>eight tokens &mdash; swiss-editorial, post-digital-green, +6.</span></li>
