  <section>
    <h1>design eval for models that cannot<br>see their own slop</h1>
    <p class="lede dim">
      ahd is a framework. it compiles a brief into constraints, lints the
      output against 28 rules, runs n-of-k evals across frontier models,
      and asks a vision critic whether the rendered page looks like the
      thing the brief described. it does not moralise. it grades.
    </p>
    <p class="lede">
      you already have an opinion about machine-generated interfaces.
      this page is the short version of what we do about it.
      <a href="https://github.com/ahd-framework/ahd" class="cta">read the code &rarr;</a>
    </p>
  </section>

  <hr>

  <!-- rule: ASCII diagram required, rendered as text -->

    <h2>pipeline</h2>

   brief.yml                                                   scorecard

  +----------+   tokens   +--------+   n=10   +--------+   png   +--------+
  | compiler |----------->| models |--------->| render |-------->| critic |

  <!-- rule: terminal-aesthetic code block, bash, exact command required -->
  <section>
    <h2>run one eval</h2>
    <p class="dem dim">
      ten renders of a swiss-editorial brief across a given spec of models.
      fails loudly if the critic score falls below the brief's floor.
    </p>
    <pre class="code" aria-label="bash command">
<span class="lang"># bash</span><span class="prompt">$ </span>ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10<span class="caret"></span>
    </pre>
  </section>

      <ul class="manifest ships">
