    <p>
      you have already seen the slop. pages that look like a model averaged
      every landing page it ever ingested, then centred the result. ahd is the
      counter-stack: a brief compiler, a linter with teeth, an eval harness
      that scores output against the brief, and a vision-critic that looks at
      the rendered pixels and tells the model where it lied.
    </p>
    <p style="margin-top:12px;">
      no taste-by-vibes. no &ldquo;make it pop&rdquo;. the brief is the contract.
      everything else is enforcement.<span class="caret">&nbsp;</span>
    </p>
  </section>

    <div style="height:8px;"></div>
    <pre><span class="lang">bash</span><code>$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10</code></pre>

      critiques, scores. exit code is non-zero if the median run fails the

  <section>
    <h2>what ships</h2>
    <div style="height:8px;"></div>
    <ul class="manifest">
      <li><span class="tag">[ship]</span><span>brief compiler &mdash; yaml &rarr; authoritative json spec, with required/forbidden lists.</span></li>
      <li><span class="tag">[ship]</span><span>28-rule linter &mdash; static checks against the spec (radii, shadows, tokens, copy bans).</span></li>
      <li><span class="tag">[ship]</span><span>eval harness &mdash; deterministic runner, n samples, seeded prompts, diffable verdicts.</span></li>
      <li><span class="tag">[ship]</span><span>vision-critic scaffold &mdash; rubric + prompt + parser; brings your own multimodal model.</span></li>
      <li><span class="tag">[ship]</span><span>mcp server &mdash; exposes compiler, linter, harness as tools for any agent.</span></li>
      <li><span class="tag">[ship]</span><span>editor plugins &mdash; vscode and zed; lint-on-save against the active brief.</span></li>
      <li><span class="tag">[ship]</span><span>eight tokens &mdash; post-digital-green, swiss-editorial, brutalist-print, terminal-amber, bauhaus-grid, mono-noir, plotter-line, low-fi-zine.</span></li>
    </ul>
