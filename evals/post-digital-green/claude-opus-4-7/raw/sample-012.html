A framework against design slop.

You have seen the landing pages. Purple-to-blue hero. Pill badge, two CTAs, three equal cards, a trusted-by strip nobody earned. The slop is a solved problem — just not by the tools that produced it.

AHD is a compiler, a linter, and an eval harness that treats design output the way we already treat code: write a brief, run it against frontier models, fail the bad ones, keep the receipts.

▸ read the code on github  · forgejo mirror available

The one-liner

Everything below is real. Pipe the results anywhere. The brief is YAML, the models are a spec list, ten generations is the default sample because nine is superstitious and eleven is expensive.

~/ahd  —  zsh bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# → compiles brief, runs 10 generations per model, lints each,
# → scores against the 28 rules, writes ./out/eval-2026-04-24/.

Yes, --models <specs> is literal. Substitute your provider strings. The harness does not care which vendor loses.

What ships

Installed by pipx install ahd. Works offline against fixture models. No API key required to see the linter fail a gradient hero.

  • 01Brief compiler — YAML → structured intent, constraints, counter-examples.ships
  • 0228-rule linter — typographic, spatial, semantic; each rule is a named, testable function.ships
  • 03Eval harness — N generations, scored, diffed, archived as signed JSON.ships
  • 04Vision-critic scaffold — rendering pipeline and rubric; plug in your own multimodal model.ships
  • 05MCP server — expose AHD to any MCP-capable client; stdio and socket transports.ships
  • 06Editor plugins — Neovim, VS Code, Zed; in-tree, loaded as local extensions.ships
  • 07Eight tokens — ink, paper, rule, accent, muted, term, void, signal. Enough to refuse the rest.ships

What is gated

Not vapour — just dependent on things we won't ship you for free or cannot ship you at all. Each gate is documented; none of them block the offline path.

  • g1Live frontier-model calls needs API keysgated
  • g2Live vision critique needs multimodal key + screenshot pipelinegated
  • g3Standalone npm packages for editor plugins tracked in issue #142gated
  • g4Additional tokens semantic, data-viz, motion — under reviewgated
