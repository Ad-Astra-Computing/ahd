AHD / Artificial Human Design v0.3 · 2026-04

You already know what slop looks like.
This is the eval that refuses to produce it.

AHD is a framework for treating design output from a language model the same way you treat code from one: with a brief, a linter, a test harness, and a critic that can see the screen.

No lecture on why the generated landing pages all rhyme. You have a tab open to one right now. The question is what runs between the prompt and the pull request.

The thesis, short. Generation without evaluation is the slop. AHD is the evaluation — a brief compiler, a rule set, and a vision critic, wired so a single command reproduces the run on your machine.

The one-liner§ 01 · run

bash · ~/ahd 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Ten generations per model, scored against the brief and the 28-rule linter, screenshotted, then fed to the vision-critic. Exit code is non-zero if the median output violates the brief.

What ships§ 02 · today, in the repo

brief compiler
YAML → structured constraint set; deterministic, diffable, versionable.
28-rule linter
Static checks for the generated HTML/CSS — hierarchy, contrast, grid honesty, typographic scale, the usual suspects that rhyme.
eval harness
Runs N generations, aggregates scores, emits a reproducible report and a failure set.
vision-critic
Scaffold for rendered-screenshot critique; stub provider included, no keys required to exercise the interface.
MCP server
Exposes the brief, rules, and harness as tools so any MCP-capable client can drive a run.
editor plugins
VS Code and Zed plugins in-tree: inline lint on save, run-eval command, failure surfacing.
eight tokens
A starter token set — ink, paper, rule, muted, accent, grid, measure, scale — with the semantic aliases and CC-BY artwork samples.

What is gated§ 03 · needs something you bring

frontier calls
Live calls to closed frontier models. Needs your own API keys; we will never proxy them.
live vision critique
The critic running against real screenshots. Needs a multimodal key plus the headless-browser screenshot pipeline configured.
npm packages
Standalone, versioned npm distributions for the editor plugins. In-tree today, published on the next tagged release.
additional tokens
Beyond the eight: motion, density, editorial-long-form, data-dense. Drafted, not yet audited; held until they survive their own eval.
