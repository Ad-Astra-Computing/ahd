ahd.artificial-human-design
v0.3.2  ·  source

A framework, not a lecture.

You already know the web is full of slop. AHD is the harness that measures it.

AHD is a compiler, a linter, and an eval harness for design output. You write a brief, it compiles to a rubric, the rubric grades generated pages against typographic, editorial, and compositional rules that a senior designer would actually defend.

Nothing here is a plugin for taste. The rules are explicit, versioned, and diff-able. If a model fails a rule, the run prints the rule id, the offending selector, and the measurement. No vibes.

01 What ships

Installed today. Runs offline. Reproducible from a lockfile.

  • 01 Brief compiler ships YAML brief → structured rubric with measurable acceptance criteria.
  • 02 28-rule linter ships Hierarchy, rhythm, optical alignment, measure, widow control, rule-id traceable failures.
  • 03 Eval harness ships Headless runner, deterministic seeds, per-model scorecards, JSON + HTML reports.
  • 04 Vision-critic scaffold ships The plumbing for screenshot + VLM review; local stub provided, pluggable backends.
  • 05 MCP server ships Exposes compile, lint, eval, and critique to any MCP-aware client.
  • 06 Editor plugins ships In-repo packages for VS Code, Zed, and Neovim. Inline rule-ids in the gutter.
  • 07 Eight tokens ships A tight starter palette: two type stacks, a modular scale, a measure, three colour roles, a rule weight.

02 What is gated

Works with the framework but requires something we do not ship.

  • 01 Live frontier-model calls gated Needs API keys. Bring your own provider; the harness reads them from the environment.
  • 02 Live vision critique gated Needs a multimodal key plus a screenshot pipeline (Playwright + a reachable VLM endpoint).
  • 03 Standalone npm packages for the editor plugins gated Currently vendored in the monorepo. Separate publish cadence is deliberate, not decided.
  • 04 Additional tokens gated Extended palettes, display faces, and motion tokens land behind a token-pack licence.

If something you expect is in neither list, it is not a roadmap item yet.
