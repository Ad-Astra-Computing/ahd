  <h1>You've already seen the problem. <em>AHD is the framework that takes it seriously.</em></h1>

  <p class="dek">A measurable practice for design that isn't sludge — a brief compiler, a linter, a live eval harness, and a vision critic you can actually point at a generation.</p>

  <div class="lede">
    <p>You don't need another essay about generated interfaces that all look like the same beige SaaS page. You've opened ten tabs this week and closed nine. The thesis — that the defaults collapse toward a narrow aesthetic attractor — is not in dispute here.</p>
    <p>AHD is a toolchain. It compiles an explicit brief, lints a draft against 28 rules derived from Swiss and editorial practice, runs N generations across models, and then scores the pixel output with a vision critic. You can read the rules. You can change the rules. You can run the eval on your own brief in about a minute.</p>
  </div>

  <div class="term" aria-label="Terminal: run the eval">

  <section id="ships">
    <div class="section-head"><span class="num">01 —</span><h2>What ships</h2></div>
    <ul class="manifest">
      <li><span class="k">brief compiler</span><span class="v">YAML → structured brief with constraints, references, and banned moves.</span></li>
      <li><span class="k">28-rule linter</span><span class="v">Static checks for grid, type scale, contrast, rhythm, and the usual generated tells.</span></li>
      <li><span class="k">eval harness</span><span class="v">Runs N generations per model, captures artifacts, writes a reproducible report.</span></li>
      <li><span class="k">vision critic</span><span class="v">Scaffolded pipeline for rendering output and scoring it against the brief.</span></li>
      <li><span class="k">MCP server</span><span class="v">Exposes the brief, rules, and critic to any MCP-aware client or agent.</span></li>
      <li><span class="k">editor plugins</span><span class="v">In-repo integrations for VS Code, Zed, and Neovim. Installed from source.</span></li>
      <li><span class="k">eight tokens</span><span class="v">A deliberately small starter set — two typefaces, four neutrals, two accents.</span></li>
    </ul>
  </section>

  <section id="gated">
    <div class="section-head"><span class="num">02 —</span><h2>What is gated</h2></div>
    <ul class="manifest gated">
      <li><span class="k">frontier calls</span><span class="v">Live runs against current frontier models. Requires your own API keys; no proxy.</span></li>
      <li><span class="k">vision critique</span><span class="v">Live scoring needs a multimodal key and the screenshot-render pipeline attached.</span></li>
      <li><span class="k">npm packages</span><span class="v">Standalone, versioned releases of the editor plugins. Currently source-only.</span></li>
      <li><span class="k">more tokens</span><span class="v">Additional token packs beyond the starter eight — shipping as they stabilise.</span></li>
    </ul>
  </section>
