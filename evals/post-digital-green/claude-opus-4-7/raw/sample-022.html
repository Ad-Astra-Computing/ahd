AHD/artificial-human-design
v0.4.2 · 2026-04-24

A framework for the slop problem, not another lecture about it.

You have looked at twelve generated landing pages this month. Same hero, same three cards, same shimmer on the word that must not be named. You already know why. AHD is the part that comes after knowing.

It is a brief compiler, a linter that reads like taste written down, and an eval harness that runs the same brief across models so you can see, in numbers, which ones produce work you would actually sign.

Premise. Generated design fails at the editorial layer — rhythm, restraint, specificity — long before it fails at CSS. AHD treats those properties as measurable, not as vibes. The rules are open. Disagree in a pull request.
~/ahd bash 
# Run the live eval against the swiss-editorial rubric, ten samples per model.
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

What ships

[ 01 / in the box today ]
  • 01
    Brief compiler YAML in, structured intent out. The same brief drives every downstream stage so runs are comparable.
  • 02
    28-rule linter Editorial rules with citations: hero-stack detection, gradient-on-AI, three-card symmetry, pill-plus-two-CTA, Corporate Memphis, and twenty-three more.
  • 03
    Eval harness Deterministic runner with seeded sampling, per-rule scoring, and a diff view across models for the same brief.
  • 04
    Vision-critic scaffold The prompts, the rubric, the report format. Bring your own multimodal key to make it breathe.
  • 05
    MCP server Stdio transport, exposes the compiler, linter, and harness as tools. Tested against the two reference clients.
  • 06
    Editor plugins Zed and VS Code integrations in-tree. Inline lint, hover explanations, quick-fix on a handful of rules.
  • 07
    Eight tokens A base palette, typographic scale, rhythm unit, and six composable shape primitives. CC-BY-4.0.

What is gated

[ 02 / requires external resources ]
  • G1
    Live frontier-model calls → needs API keys The harness runs locally on fixtures out of the box. Pointing it at live models is one env-var away — the bill is yours.
  • G2
    Live vision critique → needs multimodal key + screenshot pipeline The scaffold is in-tree. End-to-end critique needs a vision-capable key and a screenshot worker you host.
  • G3
    Standalone npm packages for the editor plugins → publishing pipeline pending Plugins work from source today. Registry distribution is waiting on release tooling, not on consent.
  • G4
    Additional tokens → commissioned from external studios Expanded palettes, motion primitives, and editorial grids will ship as separate CC-BY-4.0 releases as partners land.
