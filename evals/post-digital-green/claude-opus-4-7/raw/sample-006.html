AHD / Artificial Human Design v0.4.2 · github.com/ahd/ahd

A framework for design that refuses to look generated.

AHD is a brief compiler, a linter, and a live evaluation harness. It runs against frontier models on every commit and fails the build when the output drifts toward the average.

You have already seen the pattern this month. The centred hero. The three equal cards. The pill badge above two buttons. The shimmer on the word that everyone is tired of. Models converge on a mode; the mode becomes the web; the web becomes wallpaper.

AHD treats that convergence as a measurable defect. A brief is compiled to constraints. A 28-rule linter rejects the worst of the regression. An eval harness re-runs the brief against named model versions, scores the artefacts with a vision critic, and writes the diff back into the repo.

Stance why this exists

The argument is not that models are bad. The argument is that an unmeasured pipeline produces unmeasured work, and that the median web page now reads like a prompt that was never edited. AHD is the editing layer: a deterministic compiler in front of a non-deterministic generator, and a critic behind it.

It does not replace the designer. It removes the designer's excuse for shipping the average.

What ships today, in this repo

brief compiler
YAML in, typed constraint graph out. Deterministic, hashable.
28-rule linter
Static checks for the common regressions (equal-card grids, pill+two-CTA hero, gradient-on-AI, etc.).
eval harness
Runs a brief against N models × K seeds, persists artefacts and scores under evals/.
vision-critic scaffold
Local interface, schema, and golden cases. Wires to a model when one is provided.
MCP server
Exposes the compiler, linter, and eval harness to any MCP-aware editor.
editor plugins
VS Code and Zed, in-tree, loaded from source.
eight tokens
The reference set: ink, paper, rule, accent, mute, term-bg, term-fg, term-dim. CC-BY-4.0.

What is gated requires external resources

frontier calls
Live generation against frontier models — needs API keys you supply in .env.
vision critique
Live scoring of rendered pages — needs a multimodal key and the screenshot pipeline (Playwright + worker).
npm packages
Standalone, published builds of the editor plugins. In-tree today, registry tomorrow.
additional tokens
Expanded palettes, type scales, and motion sets beyond the reference eight.
