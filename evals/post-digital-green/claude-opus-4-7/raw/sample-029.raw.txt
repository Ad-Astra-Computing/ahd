    <h1 class="hed">A framework for design that <em>isn't</em> generated slop.</h1>

    <p class="dek">You've spent the last month closing tabs on centred hero stacks, pill badges, and three-card feature strips. You don't need another essay about it. AHD is the working apparatus: a brief compiler, a linter that knows the twenty-eight tells, and an eval harness that actually runs the models against a rubric instead of a vibe.</p>

    <p class="dek">It is small, legible, and opinionated. Read the source in an afternoon. Disagree with the rubric in the morning.</p>

    <div class="cta-row">
      <a class="primary" href="https://github.com/ahd/ahd">Read the code →</a>

    </div>

    <hr class="rule">
    <p class="section-label"><span class="num">§01</span>What ships</p>
    <h2 class="sec">Shipping today.</h2>
    <p class="sec-sub">Everything below is in the repo, runs locally, and has no external dependency beyond Node 20 and a working terminal.</p>

    <ol class="manifest ships">
      <li>
        <span class="idx">01 / 08</span>
        <span class="name">Brief compiler</span>
        <span class="desc">YAML → constraint graph. Resolves tokens, enforces schema, emits a typed brief the harness can actually dispatch.</span>
      </li>
      <li>
        <span class="idx">02 / 08</span>
        <span class="name">28-rule linter</span>
        <span class="desc">The tells, enumerated. Hero-stack-centred, gradient-on-AI, three-equal-cards, emoji-bullets, purple-to-blue, and twenty-three more.</span>
      </li>
      <li>
        <span class="idx">03 / 08</span>
        <span class="name">Eval harness</span>
        <span class="desc">Dispatch <code>N</code> renders across model specs, score against the rubric, write a static HTML report you can diff across runs.</span>
      </li>
      <li>
        <span class="idx">04 / 08</span>
        <span class="name">Vision-critic scaffold</span>
        <span class="desc">The prompt, the rubric, the runner, and a mock adapter that replays fixtures. Swap in a real multimodal key when you have one.</span>
      </li>
      <li>
        <span class="idx">05 / 08</span>
        <span class="name">MCP server</span>
        <span class="desc">Expose the compiler, linter, and harness as tools to any MCP-aware editor or agent. Stdio and HTTP transports.</span>
      </li>
      <li>
        <span class="idx">06 / 08</span>
        <span class="name">Editor plugins</span>
        <span class="desc">First-party integrations for VS Code, Zed, and Neovim. Lint on save, compile brief under cursor, run eval from command palette.</span>
      </li>
      <li>
        <span class="idx">07 / 08</span>
        <span class="name">Eight tokens</span>
        <span class="desc">A deliberately small set: ink, paper, rule, accent, muted, term-bg, term-ink, term-accent. Enough for an editorial page. Not enough to hide behind.</span>
      </li>
      <li>
        <span class="idx">08 / 08</span>
        <span class="name">Reference briefs</span>
        <span class="desc">Swiss-editorial, documentation, technical-marketing. The YAMLs this page was scored against are in <code>/briefs</code>.</span>
      </li>
    </ol>

    <hr class="rule">
    <p class="section-label"><span class="num">§02</span>What is gated</p>
    <h2 class="sec">Gated on external resources.</h2>
    <p class="sec-sub">These work, but they require something we cannot ship in the repo itself — a key, a pipeline, a registry account. Each has a local mock you can run against in the meantime.</p>

    <ol class="manifest gated">
      <li>
        <span class="idx">A</span>
        <span class="name">Live frontier-model calls</span>
        <span class="desc">Needs API keys. Configure <code>AHD_KEYS</code> or a <code>.ahd/secrets.toml</code>; the harness will route automatically. Without keys it runs against recorded fixtures.</span>
      </li>
      <li>
        <span class="idx">B</span>
        <span class="name">Live vision critique</span>
        <span class="desc">Needs a multimodal key plus the screenshot pipeline (Playwright + a headless Chromium). Scaffold is present; the runner is wired; the external bits are yours to provide.</span>
      </li>
      <li>
        <span class="idx">C</span>
        <span class="name">Standalone npm packages for the editor plugins</span>
        <span class="desc">The plugins are in-tree and install from source today. Published registry packages are pending a namespace decision and a release workflow.</span>
      </li>
      <li>
        <span class="idx">D</span>
        <span class="name">Additional tokens</span>
        <span class="desc">The set stays at eight in core. Extended palettes (documentation, dense-data, print) ship as separate token packs when the corresponding briefs are stable.</span>
      </li>
    </ol>
