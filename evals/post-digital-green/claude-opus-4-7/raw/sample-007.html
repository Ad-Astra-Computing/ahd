AHD // ARTIFICIAL HUMAN DESIGN v0.4 · 2026-04
A framework, not a lecture.

The slop problem is a measurement problem.

You have seen the sites. Purple-to-blue hero. Pill badge. Three equal feature cards. A canonical four-column footer. It is not that the models are bad; it is that nobody is grading them against a brief any human would recognise as one.

AHD compiles a brief into a structured target, lints the output against 28 rules a senior designer would mark in red, and re-runs the whole thing every time a model ships. The output is not a theme. It is a score.

01Run the eval yourself

One line. It loads the brief, dispatches to the model specs you pass, scores ten generations per spec against the linter, and writes a diffable report to ./out. No account, no telemetry.

~/ahd bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# swiss-editorial is one of four starter rubrics. Bring your own with briefs/*.yml.

02What ships

Today. In the repo. No waitlist, no key required.

  • ✓ in repo brief compiler YAML → structured target: tone, grid, type scale, do/don't clauses the linter can read.
  • ✓ in repo 28-rule linter Static rules for layout, hierarchy, colour contrast, cliché detection. Runs on HTML strings.
  • ✓ in repo eval harness Dispatches a brief to N models, collects generations, scores, produces a report.
  • ✓ in repo vision-critic scaffold The prompt templates, rubric, and parser. Works with any multimodal model you plug in.
  • ✓ in repo MCP server Exposes the compiler, linter, and harness as tools to any MCP-speaking client.
  • ✓ in repo editor plugins VS Code and Zed integrations: lint-on-save, brief inference, hover diagnostics.
  • ✓ in repo eight tokens A deliberately small starter set: ink, paper, rule, muted, accent, focus, term-bg, term-fg.

03What is gated

Not secret. Just dependent on things we do not own.

  • ◌ gated live frontier-model calls Needs your own API keys. The harness runs offline against fixtures until you supply them.
  • ◌ gated live vision critique Needs a multimodal key and the screenshot pipeline (headless Chromium + storage).
  • ◌ gated standalone npm packages for the editor plugins Currently vendored inside the monorepo. Extraction is queued, not done.
  • ◌ gated additional tokens Beyond the core eight. Each needs a rationale and a linter rule before it lands.

04Why bother

Because "it looks fine" is not a review, and "the model did it" is not a defence. If a generator cannot pass a brief a human wrote, you do not have a design tool; you have a decorator with a large vocabulary. AHD is the grader.
