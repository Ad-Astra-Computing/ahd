AHD / Artificial Human Design v0.4 · 2026‑04‑24 · read the code →

The slop is real. AHD is a framework for not making more of it.

You've scrolled through the same generated layout fourteen times this month: a centred hero, a pill badge, two CTAs, three equal feature cards, a logo strip, a purple gradient somewhere. You already know what's wrong. AHD is a toolchain that treats that pattern as a bug and writes evals against it.

AHD compiles a brief into a structured spec, lints the output against 28 rules that encode things working designers already argue about in code review (rhythm, hierarchy, restraint, the ban on the pill badge), and runs a live eval harness that re‑generates the page across n frontier models so you can watch the distribution of slop instead of guessing at it.

~/ahdbash
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10
# compiles brief · runs n=10 per model · lints · scores · diffs against the rulebook

Reads real. Runs real, if you bring keys. Otherwise runs against fixtures shipped in the repo.

What ships

in repobrief compiler
YAML brief → structured spec (constraints, grid, token set, refusal list). Deterministic, diffable.
in repo28‑rule linter
Static rules over the rendered DOM and CSS. Catches the pill‑badge hero, the three‑card row, the AI‑shimmer, gradient‑text on the word AI, and twenty‑four other things.
in repoeval harness
Runs a brief across an arbitrary model list, n times each. Emits a scored matrix, a diff view, and a per‑rule failure histogram.
in repovision‑critic scaffold
Pluggable critic interface, screenshot adapter, prompt templates, golden outputs. Works offline against stored renders.
in repoMCP server
Exposes the brief compiler, the linter, and the harness as MCP tools so an agent in your editor can call them directly.
in repoeditor plugins
VS Code and Zed plugins, in‑tree, wired to the MCP server. Inline rule violations, quick‑fix hints, brief preview.
in repoeight tokens
A small, opinionated token set — type scale, spacing, measure, two inks, one paper, one accent, one rule — enough to render this page and not much else on purpose.

What is gated

gatedlive frontier‑model calls
Needs your API keys. The harness runs end‑to‑end against fixtures without them; flip a flag and the same harness hits real endpoints.
gatedlive vision critique
Needs a multimodal key and the screenshot pipeline (headless browser + capture worker). The scaffold is in‑tree; the live path is opt‑in.
gatedstandalone npm packages for the editor plugins
Plugins run from the monorepo today. Independent, versioned npm releases are on the roadmap, not on disk.
gatedadditional tokens
Further token families (editorial display, data, marque) exist as drafts. They are not part of the eight that ship.
