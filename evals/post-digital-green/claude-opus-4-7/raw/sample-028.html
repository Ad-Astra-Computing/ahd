A framework for catching the slop before it ships.

You have already seen the pattern: the centred hero, the pill badge, the purple-to-blue gradient, the four-column footer that no one reads. AHD is the toolchain that names those failures, lints for them, and runs the eval against live models so you can argue from receipts.

§ 01 · Premisewhy this exists

The slop is not a vibe. It is a measurable collapse onto a small set of layout templates, copy registers, and component idioms that the current crop of generators reach for by default.

AHD treats that collapse as a regression. Briefs are compiled to constraints. Constraints become lint rules. Lint rules become eval criteria. The same artefact that grades a model grades your own draft.

§ 04 · Usehow to start

Clone the repo. Write a brief. Run the one-liner above against whichever models you have keys for. Read the report; the failures will be familiar. File issues against the rules you disagree with — the lint set is meant to be argued with, not deferred to.

AHD is not a generator. It will not write your landing page. It will tell you, with citations, when the page you wrote looks like the median of the training set.
