  <section class="hero">
    <h1>A framework for design that survives <em>being generated.</em></h1>
    <p class="lede">You have probably audited four AI-generated sites this month. You already know the pattern: the centred hero, the pill badge, the three equal cards, the purple gradient on the word <span style="font-style:italic">AI</span>. AHD is not an argument about taste. It is an eval harness and a compiler that makes the argument reproducible.</p>
    <p>You write the brief, AHD lints it against 28 editorial rules, compiles it to eight tokens and a component contract, then runs <span style="font-family:monospace; font-size:15px;">n=10</span> generations across whatever frontier models you point it at. A vision critic reads the screenshots back. You look at the diff, not the marketing copy.</p>

    <h2><span class="num">01</span> Run the eval</h2>
    <div class="term" aria-label="terminal">
      <div class="term-bar">
        <span>~/proj/landing — zsh</span>
        <span class="lang">bash</span>
      </div>
      <div class="term-body"><span class="p">$</span> <span class="cmd">ahd eval-live swiss-editorial <span class="flag">--brief</span> <span class="str">briefs/landing.yml</span> <span class="flag">--models</span> <span class="str">&lt;specs&gt;</span> <span class="flag">--n</span> <span class="str">10</span></span></div>
    </div>
    <p class="caption">Resolves the brief, lints, compiles tokens, fans out <span style="font-family:monospace">n=10</span> generations per model, captures screenshots, and scores them against the vision critic. Exits non-zero if the median score drops below the floor in <span style="font-family:monospace">ahd.toml</span>.</p>
  </section>

  <section class="section">
    <h2><span class="num">02</span> The thesis, briefly</h2>
    <div class="thesis two-up">
      <div>
        <p>Slop is not a style problem. It is an <b>evaluation</b> problem. Models optimise for the reward you give them, and if the reward is "looks like a SaaS landing page," the output regresses to the mean of SaaS landing pages ever scraped.</p>
      </div>
      <div>
        <p>AHD replaces that reward. The brief compiler produces a machine-checkable contract; the linter rejects the 28 most common regressions before a model ever sees the prompt; the vision critic grades the render, not the tokens in the response.</p>
      </div>
    </div>
  </section>

  <section class="section">
    <h2><span class="num">03</span> What ships</h2>
    <div class="manifest">
      <dl class="list">
        <div><dt class="k">A</dt><dd class="v"><b>Brief compiler.</b> <span class="note">YAML → typed contract, tokens, and component shape. Deterministic.</span></dd></div>
        <div><dt class="k">B</dt><dd class="v"><b>28-rule linter.</b> <span class="note">Catches centred-hero-pill-two-CTAs, three-equal-cards, gradient-on-AI, shimmer, Memphis, iridescent blobs, and 22 more.</span></dd></div>
        <div><dt class="k">C</dt><dd class="v"><b>Eval harness.</b> <span class="note">Fan-out, screenshot capture, scoring, regression report. Works against any model with a completions endpoint.</span></dd></div>
        <div><dt class="k">D</dt><dd class="v"><b>Vision-critic scaffold.</b> <span class="note">Prompt templates, rubric, scorer, diff viewer. Ships without keys.</span></dd></div>
        <div><dt class="k">E</dt><dd class="v"><b>MCP server.</b> <span class="note">Exposes the compiler and linter to any MCP-aware editor or agent.</span></dd></div>
        <div><dt class="k">F</dt><dd class="v"><b>Editor plugins.</b> <span class="note">In-tree source for VS Code, Zed, Neovim. Run them from the monorepo today.</span></dd></div>
        <div><dt class="k">G</dt><dd class="v"><b>Eight tokens.</b> <span class="note">Type pair, scale, measure, rule-weight, paper, ink, muted, flag. The working set for editorial layouts.</span></dd></div>
      </dl>
    </div>
  </section>

  <section class="section gated">
    <h2><span class="num">04</span> What is gated</h2>
    <div class="manifest">
      <dl class="list">
        <div><dt class="k">i</dt><dd class="v"><b>Live frontier-model calls.</b> <span class="tag">keys</span> <span class="note">The harness runs offline against fixtures out of the box. To hit real models you bring your own API keys.</span></dd></div>
        <div><dt class="k">ii</dt><dd class="v"><b>Live vision critique.</b> <span class="tag">multimodal + pipeline</span> <span class="note">Needs a multimodal key and a working screenshot pipeline (headless Chromium, a device matrix, and storage).</span></dd></div>
        <div><dt class="k">iii</dt><dd class="v"><b>Standalone npm packages for the editor plugins.</b> <span class="tag">registry</span> <span class="note">Sources are in-tree today; published packages arrive when the plugin API freezes.</span></dd></div>
        <div><dt class="k">iv</dt><dd class="v"><b>Additional tokens.</b> <span class="tag">roadmap</span> <span class="note">Beyond the working eight: motion, density, and a dark-paper set. On the roadmap, not in <span style="font-family:monospace">main</span>.</span></dd></div>
