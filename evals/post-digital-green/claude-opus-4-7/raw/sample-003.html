AHD Artificial Human Design
v0.3.1  ·  git

A framework for design that is not slop.

You have opened maybe forty landing pages this month that all look like the same shimmering purple thing — pill badge, two buttons, three equal cards, Trusted-by strip, Corporate-Memphis people holding abstract shapes. You already have the diagnosis. AHD is the workbench.

It is a brief compiler, a linter with opinions, and an eval harness that runs real models against a real rubric. You read the results. You keep what holds up. You throw out the rest. There is nothing to sign up for.

01Run the eval

bash ~/ahd 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# compiles brief → runs n=10 samples per model → scores against 28-rule linter
# writes out/eval-2026-04-24/ with rendered HTML, screenshots, rubric JSON

Swap swiss-editorial for any registered aesthetic. The brief file is plain YAML; the rubric is plain text. If a rule is wrong, edit it.
