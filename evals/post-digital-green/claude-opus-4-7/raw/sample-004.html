A framework for design that reads like it was done on purpose.

You have seen the output. Centred hero, pill badge, three feature cards, a gradient on the word AI. The problem is not taste; it is that nobody is grading the work. AHD is a compiler, a linter, and an eval harness for layout — the same loop an engineer gets from tests, pointed at the thing designers have been defending with vibes.

It is open source. It runs locally. It will tell you, in writing, that your model produced slop — and, where it can, why.

01 Run the eval

One command. It compiles a brief, generates n candidates against the models you name, runs the 28-rule linter, and scores each against the swiss-editorial rubric. Output is a diffable report, not a vibe. 

bash$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# writes ./out/<run-id>/{report.md, lint.json, shots/*.png}
<specs> — comma-separated model IDs; see README for the accepted forms.

02 What ships

Everything below is in the repo today. Clone, install, run. No waitlist.

  • 01Brief compiler — YAML in, constrained prompt + rubric out.shipped
  • 0228-rule linter for the generated HTML/CSS (grid, hierarchy, anti-patterns).shipped
  • 03Eval harness — deterministic runs, JSON reports, diffable across models.shipped
  • 04Vision-critic scaffold — rubric, prompt chain, adapter interface.shipped
  • 05MCP server — expose the compiler, linter, and harness to any MCP client.shipped
  • 06Editor plugins — VS Code and Zed, in-tree.shipped
  • 07Eight tokens — type scale, spacing, colour, radius, grid, motion, shadow, ink.shipped

03 What is gated

Honest about the dependencies. These work when you bring the keys or the infrastructure.

  • 01Live frontier-model calls — needs your API keys; nothing is proxied.keys
  • 02Live vision critique — needs a multimodal key and a screenshot pipeline.keys + pipeline
  • 03Standalone npm packages for the editor plugins.packaging
  • 04Additional tokens beyond the core eight.roadmap
If a claim is not on one of these two lists, it is not part of AHD. That is the point of having two lists.
