  <section class="thesis">
    <p class="eyebrow">A framework, not a lecture</p>
    <h1>You have already noticed the <em>slop</em>. AHD is what we do about it.</h1>
    <p class="lede">
      AHD is a toolchain for running design briefs through frontier models under
      constraint, then grading the output against a fixed rubric before a human
      ever sees a pixel. It is not a generator. It is an eval harness pointed at
      the part of the craft that has started to collapse.
    </p>
    <p class="pull">
      The thesis is simple: if the model can pass a 28-rule Swiss-editorial linter
      and survive ten independent vision critiques, the problem is the brief, not
      the machine. If it cannot, the problem is the model, and we want that on
      the record.
    </p>
    <div class="cta-row" style="margin-top:22px">
      <a class="btn" href="https://github.com/ahd/ahd">

  </section>

    <p class="eyebrow">The manifest</p>
    <h2>What is real today, and what is not.</h2>
    <p style="color:var(--mute);max-width:62ch;margin:0 0 4px 0;">
      Every claim below maps to a file in the repo. Gated items are gated on

    <div class="manifest-grid">

      <div class="manifest shipping">
        <h2>What ships <span class="tag">today · local</span></h2>
        <ul>
          <li><span><b>brief compiler</b><span class="note">YAML → constrained prompt + grading schema.</span></span></li>
          <li><span><b>28-rule linter</b><span class="note">Structural and typographic rules, fails loudly.</span></span></li>
          <li><span><b>eval harness</b><span class="note">Deterministic n-pass runner with report output.</span></span></li>
          <li><span><b>vision-critic scaffold</b><span class="note">Interface + local stub; wiring is ready.</span></span></li>
          <li><span><b>MCP server</b><span class="note">Exposes briefs, linter, and reports to any MCP client.</span></span></li>
          <li><span><b>editor plugins</b><span class="note">VS Code and Zed, in-tree, loadable from source.</span></span></li>
          <li><span><b>eight tokens</b><span class="note">The initial Swiss-editorial set — type, space, rule.</span></span></li>
        </ul>
      </div>

      <div class="manifest gated">
        <div class="gated-head">↘ requires external keys / work</div>
        <h2>What is gated <span class="tag">not in the box</span></h2>
        <ul>
          <li><span><b>live frontier-model calls</b><span class="note">Needs API keys — bring your own, any provider.</span></span></li>
          <li><span><b>live vision critique</b><span class="note">Needs a multimodal key plus a screenshot pipeline.</span></span></li>
          <li><span><b>standalone npm packages</b><span class="note">The editor plugins are not yet published; install from source.</span></span></li>
          <li><span><b>additional tokens</b><span class="note">Beyond the initial eight — editorial, data, long-form.</span></span></li>
