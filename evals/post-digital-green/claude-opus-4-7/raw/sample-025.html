A framework, not a lecture.

The slop is not an aesthetic problem. It is an evaluation problem.

You have spent the last month closing tabs full of rounded cards, lavender gradients, and a hero that says the same thing about itself in three different weights. You already know what is wrong. AHD is the attempt to write it down as code that a machine can fail against, not as a thread that humans can nod at.

Thesis If a generator cannot be graded on a concrete brief with a concrete rubric, it will regress to the mean of the training set. The mean is the slop. So: concrete brief, concrete rubric, concrete eval, run it live on ten seeds and look at the spread.

Run the eval

One editorial brief, Swiss rubric, ten seeds, whatever model specs you pass. The harness writes a judgement sheet and a diff against the linter. No dashboard, no sign-up.

bash — ahd@local
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Replace <specs> with a comma-separated list, e.g. claude-4,gpt-5,mistral-large. Expect it to be unkind.

What shipstoday, in tree

  1. Brief compilerYAML → typed rubric + constraint set.
  2. 28-rule linterStatic rules for typographic, grid, and rhythm failures.
  3. Eval harnessSeeded runs, per-rule scoring, diff reporter.
  4. Vision-critic scaffoldPrompt templates, judgement schema, offline fixtures.
  5. MCP serverExposes brief, rubric, and linter to model clients.
  6. Editor pluginsIn-tree sources for VS Code and Zed.
  7. Eight tokensSwiss-editorial pack: type scale, grid, rhythm, ink.

What is gatedneeds external keys / work

  1. Live frontier-model callsRequires your own API keys; nothing is proxied.
  2. Live vision critiqueNeeds a multimodal key and a screenshot pipeline (Playwright recipe included).
  3. Standalone npm packages for the editor pluginsSources ship; registry publishing is not wired up yet.
  4. Additional tokensEditorial-serif, grotesk-monolith, and print-first packs are drafted, not released.

If a thing is not on the left column, assume it does not work yet. The repository will not pretend otherwise.

Why one page

Because the argument fits. A generator that cannot pass the linter on its own landing page is not going to pass it on yours. The code is short enough to read in an afternoon. The rubric is short enough to argue with. Do both.
