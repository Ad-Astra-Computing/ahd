A linter and eval harness for the design a model just produced.

You have seen the pattern. Purple-to-blue hero. Three equal feature cards. A pill badge. Two CTAs, centred. You do not need another essay about this.

AHD is the tooling around that problem. A brief compiler turns an intent document into a machine-checkable spec. A 28-rule linter flags the artefacts above, and twenty-five more. An eval harness runs a brief against a matrix of models and scores the output on typographic, compositional, and rhetorical criteria — not vibes.

It is a framework. It has opinions. It does not care whether you agree with all of them; it cares that you can read the rules, disable the ones you dislike, and add your own.

01Run the eval

One command. Resolves the brief, fans out across the models you pass, returns ten completions per model, lints each, and writes a scoreboard to ./out.

~ / project bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# <specs> is a comma list, e.g. claude-4-opus,gpt-5-high,gemini-2.5-pro

02What ships today, in the repo

brief compiler
YAML intent → typed spec. Resolves inheritance, grid, voice, and constraint clauses.
28-rule linter
Static rules over rendered DOM and tokens. Every rule is a file; every rule has a test.
eval harness
Matrix runner over models × briefs × n. Writes artefacts, diffs, and a scoreboard.
vision-critic scaffold
Pluggable interface and two reference adapters. Runs offline against fixtures.Live path is gated — see below.
MCP server
Exposes compiler, linter, and harness as tools. Works with any MCP-capable client.
editor plugins
VS Code and Zed. Inline lint, brief preview, and a "run eval on this brief" command.
eight tokens
A small, honest token set: two serif, one mono, a neutral scale, a single accent, a rule, a measure, a baseline.

03What is gated needs external resources

frontier-model calls
Live eval-live against hosted models.Requires your own API keys. Offline eval-fixture works without them.
vision critique, live
Scoring a rendered screenshot with a multimodal model.Requires a multimodal key and a working screenshot pipeline (Playwright + headless Chromium).
editor plugins, standalone
Marketplace-installable npm packages.Source is in the repo; published packages are not part of this release.
additional tokens
Editorial, technical, and archival sets beyond the core eight.Drafted, not shipped. Tracking in issues/tokens-extended.

04The thesis, in one paragraph

A model will produce the average of what it has seen. The average, right now, is a centred hero stack over a gradient. The fix is not a better prompt. The fix is a spec the model has to pass, a linter that says why it failed, and an eval loop that makes failure visible across ten runs instead of one. AHD is that loop, in a repo, under a licence you can read.

The problem is not that models cannot design. It is that nobody is grading the homework.
