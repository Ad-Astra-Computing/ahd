AHD / artificial human design
v0.4 · 2026-04

You've seen the slop. So have we. This is the eval that grades it.

AHD is a toolkit for designers who want their interfaces judged against a rubric, not a vibe. It compiles a brief, lints the output against 28 rules, runs a head-to-head eval on live models, and returns a readable artifact you can argue with.

If you already know the problem, skip the prose — run the one-liner, or read the source.

The output of a stochastic text model is not a design decision. It is a draw from a distribution. Without an eval, you are shipping the median of that distribution and calling it taste.

AHD is the thing that makes the distribution visible.

~/ahd — eval-live bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# compiles the brief, runs n=10 generations per model,
# scores each against the 28-rule linter + vision critic,
# emits ./out/eval-<ts>/report.html

one binary. one command. the rest is a report you can read on the train.

01What ships

In the repo right now, installable with a single package manager, no account required.

  • [x] Brief compiler YAML brief → typed prompt + constraint graph the linter can reason over. local
  • [x] 28-rule linter Typographic scale, contrast, rhythm, density, cliché detection. Deterministic, offline. local
  • [x] Eval harness Head-to-head n-of-k runner, scored reports, reproducible seeds. local
  • [x] Vision-critic scaffold Pluggable protocol & reference rubric. Bring your own multimodal model. local
  • [x] MCP server Exposes compiler, linter, and harness to any MCP-capable client. local
  • [x] Editor plugins In-repo integrations for VS Code, Zed, and Neovim. Live in /editors. in-tree
  • [x] Eight tokens ink, paper, rule, muted, accent, grid, measure, rhythm — the starter vocabulary. local

02What is gated

Everything below requires a resource AHD cannot ship in the tarball. The code is in the repo; the capability is not.

  • [ ] Live frontier-model calls Needs your own API keys. AHD never brokers credentials. needs: API keys
  • [ ] Live vision critique Needs a multimodal key plus a working screenshot pipeline (Playwright or equivalent). needs: multimodal + screenshots
  • [ ] Standalone npm packages for the editor plugins Plugins run today from the monorepo; individual registry releases are on a later milestone. needs: registry release
  • [ ] Additional tokens Beyond the core eight. Contributions welcome; the review bar is deliberately slow. needs: review
