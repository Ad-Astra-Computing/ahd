AHD / ARTIFICIAL HUMAN DESIGN
run ships gated

A framework for the slop, not a lecture about it.

You've spent the last month scrolling past landing pages that all lean the same direction, in the same weight, with the same rounded card at the same 24 px radius. You already know the diagnosis. AHD is the instrument panel.

AHD compiles a brief into a linter, then runs a live editorial eval across whichever frontier models you have keys for. It reports what the models did, where they collapsed to the median, and which of the 28 rules they broke. That's the whole pitch.

This page is the output of ahd eval-live swiss-editorial on its own brief. Everything you're reading is inside the harness.

01The one-liner

Run the eval against your own stack.

Point it at a brief, list the models you have access to, set the sample size. It returns a signed report and a diff against the Swiss-editorial reference.

~/ahd  ·  zsh bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# -> writes ./reports/<run-id>.jsonl and ./reports/<run-id>.html

02What ships

In the repository, today, under FSL.

These exist as code you can clone, run, and audit. No waitlist, no gated beta, no contact-for-access form.

  • 01Brief compiler — turns a YAML brief into a constraint set and a linter configuration.core
  • 0228-rule linter — the full editorial ruleset, documented, each rule with a counter-example.core
  • 03Eval harness — runs N samples per model, scores against the rules, emits JSONL + HTML.core
  • 04Vision-critic scaffold — the rendering, capture, and scoring pipeline, stubbed on the model side.scaffold
  • 05MCP server — exposes the linter and the harness as tools to any MCP-aware client.server
  • 06Editor plugins — VS Code and Zed, wired to the MCP server, source in-tree.plugin
  • 07Eight tokens — the reference palette, type scale, grid, and motion primitives, hand-authored.tokens

03What is gated

Present in the design, absent from the repo until the dependency is yours.

Everything below requires a resource AHD does not and will not ship: your keys, your pipeline, your registry credentials, your taste.

  • 01Live frontier-model calls — needs API keys you provide; no bundled keys, no proxy.keys
  • 02Live vision critique — needs a multimodal key plus a screenshot pipeline (Playwright or equivalent) you stand up.vision
  • 03Standalone npm packages for the editor plugins — source ships in-tree, published artefacts are pending a registry identity.npm
  • 04Additional tokens — anything beyond the reference eight; authored on commission, not speculatively.tokens
