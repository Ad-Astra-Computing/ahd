artificial human design web / eval / manifest

a framework for catching design slop before it ships itself into the room.

ahd turns taste into checks: compile the brief, lint the output, run the eval, inspect the misses. the point is not a lecture about generic ai design. the point is a repeatable way to reject it.

run the eval

$
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

live runs are useful because the failure mode is rarely one bad screen. it is a pattern that repeats across prompts, tokens, and models.

What is gated

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
