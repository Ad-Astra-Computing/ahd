artificial human design / evals for people who already noticed

ahd gives design judgement a surface you can inspect, lint, and run.

the problem is not that models can produce layouts. the problem is that most teams still cannot state what should be rejected, what should be compared, and what stays gated on real external systems.

ahd compiles briefs, checks them against a 28-rule linter, runs an eval harness, and leaves the boundary between local capability and external dependency visible instead of hand-waved.

what is gated

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
