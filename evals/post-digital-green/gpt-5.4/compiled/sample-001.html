artificial human design // ahd

less generated style. more accountable taste.

ahd is a working framework for turning design direction into checks, prompts, manifests, and review surfaces that can survive contact with real model output.

the point is not to moralise about slop. the point is to make vague aesthetic standards executable, inspectable, and hard to hand-wave.

what is gated

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens

method: compile the brief, lint the output, compare variants, inspect the misses, and keep the artifact trail. if a system claims taste, it should also expose the test bench.
