artificial human design / web

ahd is a framework for refusing auto-generated sameness.

it compiles a brief into constraints, lint rules, and an eval loop so a landing page can be judged against intent instead of drifting toward the same polished default.

this is for people who already know what the problem looks like. the point is not a lecture. the point is a toolchain.

brief compiler 28-rule linter eval harness read the code 
[ brief ] -> [ compile ] -> [ lint ] -> [ render ]
     |             |            |            |
     v             v            v            v
[ constraints ] [ tokens ] [ checks ] [ screenshots ]
      \______________ ahd eval-live ______________/
run the eval
$ language: bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
_ compare outputs against the brief, not against taste drift.
