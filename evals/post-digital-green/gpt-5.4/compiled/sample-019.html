ahd / artificial human design
web / one screen / 80ch

a framework for design that resists autocomplete aesthetics

ahd treats generated design as something to inspect, score, and constrain. the point is not novelty theatre. the point is a brief, a rule set, an eval loop, and enough friction to reject the usual sludge before it reaches production.

output is meant to be argued with. if a result cannot survive the rubric, it does not get promoted to a pattern.
