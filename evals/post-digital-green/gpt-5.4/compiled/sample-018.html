artificial human design / web / v0.1

ahd is a design restraint system for teams that are tired of generated sameness

ahd compiles a brief into constraints, lint rules, tokens, and evals. the point is not to ask a model for taste. the point is to define the boundaries where taste can survive contact with automation.

for working designers, senior engineers, and founders who do not need another sermon about slop. they need a runnable way to reject it.

what ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • mcp server
  • editor plugins
  • eight tokens

what is gated

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens

this is not a style gallery and not a wrapper for generic prompts. ahd treats design direction as executable policy: voice, grids, forbidden moves, required artefacts, and visible gaps between what works locally and what depends on external systems.
