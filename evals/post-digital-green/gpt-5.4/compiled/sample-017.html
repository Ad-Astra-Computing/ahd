artificial human design / ahd

a design system for catching slop before it hardens into product.

ahd turns taste into constraints you can run: compiled briefs, a linter with 28 rules, an eval harness, and the scaffolding around live visual critique. the point is not more output. the point is refusing the easy defaults that make everything look machine-averaged.

one seam left visible on purpose.

run the eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

live runs stay honest about what is local, what is deterministic, and what still depends on external model access.

what ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • mcp server
  • editor plugins
  • eight tokens

what is gated

  • live frontier-model calls (needs api keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens

ahd is for designers, engineers, and founders who want a repeatable way to reject obvious model habits without pretending taste can be outsourced.
