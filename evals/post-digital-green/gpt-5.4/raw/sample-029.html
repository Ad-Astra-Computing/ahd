Framework, not sermon

Design pressure for people who can already spot the slop.

AHD turns taste into something you can inspect, lint, run, and argue with in the open. It is for teams who do not need another generated landing page. They need a way to evaluate one before it leaks into the product.

The point is not aesthetic purity. The point is a repeatable loop: compile the brief, apply the rules, run the eval harness, and keep the judgement legible enough that a designer, engineer, and founder can disagree on specifics instead of hand-waving the whole thing away.

eval-live.sh 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
One command, ten candidate runs, one brief under pressure. Enough to expose pattern collapse, vague prompts, and brittle aesthetic claims before they become a homepage.

What ships

The current stack is usable now. These are the pieces in hand, not placeholders.

  • Brief compiler
    Turns design intent into structured input that survives handoff.
  • 28-rule linter
    Checks for the recurring failure modes that make generated work feel interchangeable.
  • Eval harness
    Runs controlled comparisons across candidates instead of relying on memory and vibes.
  • Vision-critic scaffold
    Provides the review frame and interface for visual critique.
  • MCP server
    Exposes the system in a form that tools and editors can actually use.
  • Editor plugins
    Hooks for working where briefs and prompts are written, not in a separate shrine.
  • Eight tokens
    A starter token set with enough range to be opinionated without pretending to be universal.

What is gated

These pieces depend on external services or packaging work. They are real constraints, not vague roadmap fog.

  • Live frontier-model calls
    Needs API keys.
  • Live vision critique
    Needs multimodal key + screenshot pipeline.
  • Standalone npm packages for the editor plugins
    Requires packaging and distribution outside the current integrated workflow.
  • Additional tokens
    More token packs arrive after the same rule pressure and eval process, not before it.
