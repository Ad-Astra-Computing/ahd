A framework for people already tired of generated sameness

Design evals for teams that can already spot the problem.

AHD treats design quality as something you can compile, lint, evaluate, and inspect, not hand-wave with vibes. It is for designers, engineers, and founders who do not need another lecture about slop. They need a way to test whether a page can survive professional scrutiny before it goes live.

Run the live eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What AHD does

It turns a brief into testable constraints, scores outputs against explicit rules, and keeps the review legible enough that a human can disagree with it usefully.

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
