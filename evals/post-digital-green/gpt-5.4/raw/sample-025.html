Framework over vibes

Design systems need a critic, not a costume.

AHD is for people who have already seen the pattern: the same borrowed gradients, the same soft claims, the same frictionless sameness passed off as speed. It treats generated design as something to inspect, lint, and score against an explicit brief.

One brief in, ten candidates out, then the work starts: rule checks, comparative evals, and a critic scaffold that makes judgment legible.

No lecture. No decorative manifesto. A concrete stack for teams who want a repeatable way to reject slop before it reaches production.

eval-live bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

The point is not to automate taste. The point is to expose assumptions, catch regressions, and make the output answer to the brief instead of the model's favorite landing page from last week.

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
