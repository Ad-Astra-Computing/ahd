          <div class="eyebrow">Evaluation before ornament</div>
          <h1 id="hero-title">A framework for catching design slop while it is still optional.</h1>
          <p class="lede">
            AHD is for people who can already spot the pattern: polite symmetry, generic confidence, and interfaces that pass the prompt while missing the brief. The point is not another lecture about bad outputs. The point is a repeatable way to inspect them, score them, and refuse them.
          </p>
          <div class="subgrid" aria-label="Principles">
            <div class="note">
              <strong>For designers:</strong> compile a brief into explicit constraints and visual intent instead of hoping taste survives the handoff.
            </div>
            <div class="note">
              <strong>For engineers and founders:</strong> run comparative evals against real prompts, real outputs, and a linter that is opinionated enough to matter.
            </div>
          </div>
          <a class="cta" href="https://github.com/" aria-label="read-the-code CTA">read-the-code</a>

        <section class="manifest" id="ships" aria-labelledby="ships-title">
          <h2 id="ships-title">What ships</h2>
          <p>The current kit is meant to be used, inspected, and argued with.</p>
          <ul>
            <li><div><span>brief compiler</span><br><small>turns a design brief into structured constraints and eval-ready inputs</small></div></li>
            <li><div><span>28-rule linter</span><br><small>flags familiar failure modes instead of praising fluent mediocrity</small></div></li>
            <li><div><span>eval harness</span><br><small>runs multi-sample comparisons so a single lucky output does not hide drift</small></div></li>
            <li><div><span>vision-critic scaffold</span><br><small>the review layer is defined and wired, ready for live keys where available</small></div></li>
            <li><div><span>MCP server</span><br><small>connects the workflow to tool-aware environments without inventing a new ritual</small></div></li>
            <li><div><span>editor plugins</span><br><small>in-editor access for the workflow that already exists</small></div></li>
            <li><div><span>eight tokens</span><br><small>a starting token set for deliberate visual systems, not decorative noise</small></div></li>
          </ul>
        </section>

        <section class="manifest gated" id="gated" aria-labelledby="gated-title">
