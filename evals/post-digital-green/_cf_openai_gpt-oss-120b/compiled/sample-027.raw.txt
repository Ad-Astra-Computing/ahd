<h1>artificial human design</h1>
<p>framework for designers, engineers, founders who have seen the noise. we
provide a concrete eval harness, linter, and token set that you can run on
your own hardware.</p>

<hr>

<h2 id="eval">run an eval</h2>
<pre><code class="language-bash">ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10</code></pre>

<p><a href="https://github.com/ahd/ahd" target="_blank">read the code</a></p>

<hr>

<h2 id="ships">what ships</h2>
<ul>
<li>brief compiler</li>
<li>28-rule linter</li>
<li>eval harness</li>
<li>vision-critic scaffold</li>
<li>mcp server</li>
<li>editor plugins</li>
<li>eight tokens</li>
</ul>

<hr>

<h2 id="gated">what is gated</h2>
<ul>
<li>live frontier-model calls (needs API keys)</li>
<li>live vision critique (needs multimodal key + screenshot pipeline)</li>
<li>standalone npm packages for the editor plugins</li>
<li>additional tokens</li>
</ul>
