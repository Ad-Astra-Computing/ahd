Artificial Human Design (AHD)

A concise framework for evaluating AI‑generated design outputs without the hype.

Read the code

Run an evaluation

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

This command launches the live evaluation harness against the specified model specifications.

What ships

  • Brief compiler
  • 28‑rule linter
  • Eval harness
  • Vision‑critic scaffold
  • MCP server
  • Editor plugins
  • Eight tokens

What is gated

  • Live frontier‑model calls (requires API keys)
  • Live vision critique (requires multimodal key + screenshot pipeline)
  • Standalone npm packages for the editor plugins
  • Additional tokens
