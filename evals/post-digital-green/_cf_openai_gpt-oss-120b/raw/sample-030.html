Design that stays human, even when the tools are not.

We give you a concrete framework to evaluate, lint, and iterate on AI‑augmented designs without the noise of endless generative fluff.

Run the evaluation

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

  • eval harness

  • MCP server
  • editor plugins

  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
