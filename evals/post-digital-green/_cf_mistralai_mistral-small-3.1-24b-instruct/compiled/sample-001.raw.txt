  <h1>Artificial Human Design</h1>
  <p>AHD is a framework for designers, engineers, and founders who want to take control of AI-generated design. We provide tools to evaluate, lint, and critique design outputs, ensuring that the results are meaningful and intentional.</p>

  <h2>How it works</h2>
  <p>Run the following command to evaluate a design brief:</p>
  <div class="code-block">
    <code class="language-bash">ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10</code>
  </div>

  <h2>What ships</h2>
  <ul>
    <li>Brief compiler</li>
    <li>28-rule linter</li>
    <li>Eval harness</li>
    <li>Vision-critic scaffold</li>
    <li>MCP server</li>
    <li>Editor plugins</li>
    <li>Eight tokens</li>
  </ul>

  <h2>What is gated</h2>
  <ul>
    <li>Live frontier-model calls (needs API keys)</li>
    <li>Live vision critique (needs multimodal key + screenshot pipeline)</li>
    <li>Standalone npm packages for the editor plugins</li>
    <li>Additional tokens</li>
  </ul>
