  <h1>ahd</h1>
  <p>Artificial Human Design is a framework for evaluating and critiquing AI-generated design. It provides a set of tools to ensure that AI-generated design is held to the same standards as human design.</p>
  <p>We take the slop thesis seriously and provide a framework to address it.</p>

  <h2>eval-live</h2>
  <p>Run the eval-live command to see AHD in action.</p>
  <pre><code class="language-bash">ahd eval-live swiss-editorial --brief briefs/landing.yml --models &lt;specs&gt; --n 10</code></pre>
