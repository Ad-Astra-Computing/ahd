position

No promises of magic. AHD is a working layer for briefs, rules, model comparisons, and critique hooks. It records what was asked, what was generated, and what failed.

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
