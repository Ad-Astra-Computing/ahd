AHD / Artificial Human Design

read-the-code CTA

AHD is a framework for evaluating generated interface work against explicit briefs, style tokens, lint rules, and visual critique scaffolds. less sermon, more repeatable pressure on the output. 

brief.yml --> compiler --> linter --> eval harness --> report
    |             |            |              |
 tokens       constraints   28 rules      critic scaffold
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
