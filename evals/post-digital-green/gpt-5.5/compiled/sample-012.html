ahd artificial human design / evals for generated interfaces read-the-code CTA

a design system that treats generated interfaces as testable output.

AHD compiles briefs, lints visual decisions, runs model comparisons, and leaves enough evidence for a designer or engineer to argue with the result.

Use it when taste has to survive automation, review, and repeat runs.

brief.yml
   |
   v
compiler ----> linter ----> eval harness
   |             |              |
   +-------------+--------------+
                 |

        human review*
$ run the live eval 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
