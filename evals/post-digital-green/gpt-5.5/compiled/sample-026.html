ahd
read-the-code CTA

artificial human design

ahd is an eval framework for generated interface work: briefs become constraints, constraints become checks, and checks become reviewable evidence before taste gets outsourced. 

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
brief.yml ──> compiler ──> linter ──> eval harness │ │ │ └── tokens └── rules └── scored artifacts

it does not ask teams to agree that generated design is bad. it asks the output to satisfy a brief, then leaves a trail a designer, engineer, or founder can inspect. one check is intentionally noisy.

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
