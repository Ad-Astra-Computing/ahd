ahd artificial human design read-the-code CTA

design evals for synthetic taste

AHD turns a brief, a token, and a generated surface into something that can be inspected. it is not a moodboard machine. it is a small framework for saying what the interface was asked to do, what it actually did, and where the model invented polish instead of judgement.

run the eval before the page learns to flatter you. 

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
brief.yml  ->  compiler  ->  token
    |             |             |
    v             v             v
surface    ->  linter    ->  eval log
                         \->  vision critic*

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
