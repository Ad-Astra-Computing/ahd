ahd

Artificial Human Design

AHD is an eval framework for machine-made interfaces: briefs become rules, rules become checks, checks become evidence a working designer or engineer can inspect.

read-the-code CTA 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
brief.yml -> compiler -> 28-rule linter -> eval harness -> report | | | v v v tokens vision scaffold mcp server

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
