Design evals for people with taste.

AHD treats generated interface work as something to inspect, lint, compare, and reject. It gives designers, engineers, and founders a shared frame for judging output before it reaches users.

The point is not another lecture about generic pages. The point is a runnable system: briefs become checks, checks become evals, and evals make subjective review explicit enough to improve.

run/live-eval bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
