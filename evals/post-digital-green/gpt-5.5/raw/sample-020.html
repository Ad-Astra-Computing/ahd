AHD / Artificial Human Design
read-the-code CTA

Design evaluation for people who still look at the screen.

AHD is a small framework for turning design intent into runnable checks: briefs, lint rules, live evals, and critic scaffolds that make generated interfaces easier to judge without pretending judgment is automatic.

It is for teams already tired of glossy sameness, vague taste claims, and demos that collapse under inspection. The point is not to replace critique. The point is to make critique repeatable enough that weak output has fewer places to hide.

run the landing eval bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
