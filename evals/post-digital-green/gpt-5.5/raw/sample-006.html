AHD Artificial Human Design
Read the code

Design evaluation for people who already see the pattern.

AHD turns design taste into a runnable brief, a linter, and an eval harness for AI-generated interfaces.

It is not a vibe check, a gallery, or another layer of prompt folklore. It is a small framework for saying what good means, running candidates against that standard, and keeping the failures visible.

eval-live swiss-editorial 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
