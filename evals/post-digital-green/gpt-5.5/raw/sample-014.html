AHD Artificial Human Design
read-the-code

Evaluation for generated design, before taste gets flattened.

AHD turns design briefs into repeatable checks: lint rules, live evals, critic scaffolds, and editor surfaces that make generated work answer to a standard.

Premise

Not another lecture about generic output. AHD is a working framework for teams that already see the pattern and want a stricter loop between brief, model, critique, and artifact.

run/live-eval 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
Output Structured scores, rule failures, critic notes, and fixture paths that can be inspected instead of hand-waved.

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
