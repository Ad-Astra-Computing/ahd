AHD
Artificial Human Design

Design critique that can be run, argued with, and improved.

AHD turns taste into inspectable checks: briefs, lint rules, eval runs, and critic scaffolds for teams that already know the problem is not more generated output. It is knowing which output deserves to survive.

read the code
eval command bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. brief compiler
  2. 28-rule linter
  3. eval harness
  4. vision-critic scaffold
  5. MCP server
  6. editor plugins
  7. eight tokens

What is gated

  1. live frontier-model calls (needs API keys)
  2. live vision critique (needs multimodal key + screenshot pipeline)
  3. standalone npm packages for the editor plugins
  4. additional tokens
