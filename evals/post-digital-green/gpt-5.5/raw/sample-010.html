AHD Artificial Human Design
read the code

Design evals for people who can see the difference.

AHD is a working framework for judging generated interfaces against briefs, rules, screenshots, and human taste. It treats visual quality as an artifact you can compile, lint, run, inspect, and improve.

The point is not another lecture about slop. The point is a repeatable loop: write the brief, run the eval, keep the receipts, and make the model answer to the same standards a senior reviewer would.

eval-live ready 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
