Artificial Human Design measures the parts of generated interfaces that taste alone cannot defend.

AHD is a framework for turning briefs, rules, screenshots, and model outputs into repeatable design pressure. It treats visual quality as something you inspect, lint, compare, and improve.

No synthetic applause. No decorative benchmark theater. The point is a tighter loop between prompt, artifact, critique, and the standards your team already claims to hold.

run eval bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  1. Brief compiler
  2. 28-rule linter
  3. Eval harness
  4. Vision-critic scaffold
  5. MCP server
  6. Editor plugins
  7. Eight tokens

What is gated

  1. Live frontier-model calls, which need API keys
  2. Live vision critique, which needs a multimodal key and screenshot pipeline
  3. Standalone npm packages for the editor plugins
  4. Additional tokens
