    <div class="masthead">
      <h1>A framework for evaluating <em>and</em> improving generative design output.</h1>
    </div>
    <p class="lede">
      You have already formed an opinion about AI-generated sites. AHD does not try to change it. The project provides a typed brief format, a rule-based linter, and an evaluation harness that can call vision models to score compliance&mdash;or run entirely offline against your own criteria. Read the code, run it locally, modify the rules. <a href="#manifest">The manifest below</a> states exactly what works today and what requires external setup.
    </p>

  <div class="container">
    <div class="manifest">
      <section class="manifest-section ships">
        <h2>What ships</h2>
        <ul class="items">
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              Brief compiler
              <span class="item-detail">Turns YAML briefs into typed evaluation specs with constraint validation</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              28-rule linter
              <span class="item-detail">Static analysis for layout, rhythm, type scale, and color accessibility; no model calls</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              Eval harness
              <span class="item-detail">Batch runner with deterministic seeding, output capture, and exit-code scoring</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              Vision-critic scaffold
              <span class="item-detail">Interface for multimodal critique; includes mock responses for offline development</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              MCP server
              <span class="item-detail">Model Context Protocol implementation for IDE integration</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              Editor plugins
              <span class="item-detail">Vim/Neovim and VS Code extensions for inline linting and brief completion</span>
            </div>
          </li>
          <li>
            <span class="marker">+</span>
            <div class="item-name">
              Eight tokens
              <span class="item-detail">Base token set for spacing, type, and color variables (CC-BY-4.0)</span>
            </div>
          </li>
        </ul>
      </section>

      <section class="manifest-section gated">
        <h2>What is gated</h2>
        <ul class="items">
          <li>
            <span class="marker">−</span>
            <div class="item-name">
              Live frontier-model calls
              <span class="item-detail">Requires API keys for OpenAI, Anthropic, or compatible endpoint</span>
            </div>
          </li>
          <li>
            <span class="marker">−</span>
            <div class="item-name">
              Live vision critique
              <span class="item-detail">Needs multimodal key plus screenshot pipeline (Playwright or Puppeteer)</span>
            </div>
          </li>
          <li>
            <span class="marker">−</span>
            <div class="item-name">
              Standalone npm packages for editor plugins
              <span class="item-detail">Currently source-only; registry publish gated on CI and signing setup</span>
            </div>
          </li>
          <li>
            <span class="marker">−</span>
            <div class="item-name">
              Additional tokens
              <span class="item-detail">Extended token sets for non-Latin scripts and dark-mode variants in development</span>
            </div>
          </li>
        </ul>
      </section>
