Artificial Human Design

A framework for evaluating design output,
not generating it.

AHD is built on the observation that most AI design tools optimize for speed of production, not quality of decision. This creates a predictable failure mode: coherent surfaces, broken structures, and no mechanism to catch either.

We do not generate layouts. We compile design briefs into evaluation targets, run multi-model critique against those targets, and score the gap. If you already believe the current generation of tools produces slop, AHD is the infrastructure to prove it and replace it.

bash 
ahd eval-live swiss-editorial \
  --brief briefs/landing.yml \
  --models <specs> \
  --n 10

What ships

Binary Brief compiler YAML + front-matter to typed evaluation targets
Binary 28-rule linter Structural, contrast, hierarchy, and density rules
Binary Eval harness Parallel model execution with schema-locked output
Binary Vision-critic scaffold Screenshot pipeline hooks and prompt templates
Binary MCP server Model Context Protocol for editor integration
Binary Editor plugins VS Code, Zed, Vim extension sources; build from repo
Tokens Eight tokens Design-system primitives, CC-BY-4.0 licensed
