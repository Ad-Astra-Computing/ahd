    <h1>A framework for evaluating <span class="break">design systems, not generating them.</span></h1>
    <p class="lede">You have already seen the alternative: identical layout rhythms, identical spacing, identical type hierarchies that <strong>look correct</strong> to a model trained on median web design. AHD is a toolchain for the inverse operation — structured evaluation that finds where machine output diverges from human intent.</p>

  <section>
    <div class="thesis">
      <p>The eval harness runs against your own tokens, your own briefs, your own model endpoints. The 28-rule linter encodes specific biases: it flags center-aligned hero stacks, it flags pill-badge-plus-two-CTA patterns, it flags gradient text on the word "AI" because these are not abstract aesthetic sins — they are reliable indicators that the design was optimized for a training distribution rather than a human reader.</p>
      <p>The framework does not generate. It does not "assist." It evaluates according to constraints you write, and it tells you where the constraints are violated.</p>
    </div>
  </section>

  <section>
    <h2>What ships</h2>
    <ul class="manifest">
      <li>Brief compiler — constraint language, precedence resolver, output to eval harness</li>
      <li>28-rule linter — static analysis for tokensets and generated markup</li>
      <li>Eval harness — parallel run queue, divergence scoring, report generation</li>
      <li>Vision-critic scaffold — integration points for multimodal critique pipeline <span class="note">(static analysis works without it)</span></li>
      <li>MCP server — exposes eval and lint operations to any MCP-compatible consumer</li>
      <li>Editor plugins — LSP-compatible language server + client integrations <span class="tag">from repo</span></li>
      <li>Eight tokens — CC-BY-4.0 reference tokensets for testing and calibration</li>
    </ul>
  </section>

  <section>
    <h2>What is gated</h2>
    <ul class="manifest">
      <li>Live frontier-model calls — requires your own API keys <span class="note">(eval harness defaults to local / cached runs)</span></li>
      <li>Live vision critique — requires multimodal key + screenshot pipeline setup</li>
      <li>Standalone npm packages for editor plugins — gated on CI migration to public registry</li>
      <li>Additional tokens — in development, will release under same CC-BY-4.0</li>
    </ul>
