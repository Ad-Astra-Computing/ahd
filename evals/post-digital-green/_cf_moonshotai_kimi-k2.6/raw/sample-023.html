AHD // Artificial Human Design

Evaluation over generation.

The frameworks for judging design are thinner than the frameworks for producing it. Every model can now generate a landing page in seconds. Almost nothing can tell you whether that page is any good.

AHD is a design-evaluation system: a brief compiler, a rule-based linter, and an eval harness that scores outputs against stated intent. You bring the models. We bring the criteria.

bash
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • Brief compiler YAML schema + validator for design intents
  • 28-rule linter Typography, spacing, color, and structural rules
  • Eval harness Runner, scorer, and report generator
  • Vision-critic scaffold Prompts and parser for multimodal critique
  • MCP server Model Context Protocol integration
  • Editor plugins VS Code and neovim; manual install from repo
  • Eight tokens Curated design vocabulary for evaluation contexts

What is gated

  • Live frontier-model calls Needs API keys; local inference works without
  • Live vision critique Needs multimodal key + screenshot pipeline
  • Standalone npm packages Editor plugins; pending registry publish
  • Additional tokens Expansion set; tied to community contributions
