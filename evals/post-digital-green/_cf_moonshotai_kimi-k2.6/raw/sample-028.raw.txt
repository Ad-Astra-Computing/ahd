    <div class="brand">Artificial Human Design / <span>AHD</span></div>
    <h1>A framework for evaluating design with <em>discipline</em>, not diffusion.</h1>
    <p class="lead">You have already seen the problem:夹杂物, slop, the uncanny sameness of generated interfaces. AHD does not generate. It provides a <strong>compiled brief format</strong>, a <strong>rule-based linter</strong>, and an <strong>evaluation harness</strong> that calls frontier vision models as critics—not authors.</p>
  </div>

  <div class="container">
    
    <section>
      <h2>Run an eval</h2>
      <div class="code-block">
        <div class="code-header">
          <span class="code-dot"></span>
          <span class="code-dot"></span>
          <span class="code-lang">bash</span>
        </div>
<pre><code><span class="comment"># Evaluate 10 candidates against a compiled brief</span>
<span class="flag">ahd</span> eval-live <span class="arg">swiss-editorial</span> \
  <span class="flag">--brief</span> <span class="val">briefs/landing.yml</span> \
  <span class="flag">--models</span> <span class="arg">&lt;specs&gt;</span> \
  <span class="flag">--n</span> <span class="val">10</span></code></pre>
      </div>
      <p style="font-size: 13px; color: var(--text-dim); margin-top: 8px;">The above compiles briefs/landing.yml into an evaluation schema, runs 10 candidates through the vision-critic scaffold, and returns scored results with traceable rule violations.</p>
    </section>
    
    <section class="ships">
      <h2>What ships</h2>
      <div class="manifest">
        <ul>
          <li>Brief compiler — YAML to typed evaluation schema with constraint verification</li>
          <li>28-rule linter — static analysis for spatial, typographic, and interaction rules</li>
          <li>Eval harness — orchestrates multi-model evaluation with reproducible seeding</li>
          <li>Vision-critic scaffold — structured prompting for multimodal critique (self-hosted)</li>
          <li>MCP server — Model Context Protocol integration for IDE embedding</li>
          <li>Editor plugins — current: VS Code; planned: Neovim, Zed</li>
          <li>Eight tokens — curated design vocabulary: swiss-editorial, brutalist-web, editorial-fashion, systems-debug, archival-research, craft-digital, quiet-luxury, civic-tech</li>
        </ul>
      </div>
      <div class="cta-block">
        <span class="cta-text">Source available at <code>github.com/artificial-human-design/ahd</code></span>
        <a href="https://github.com/artificial-human-design/ahd" class="btn">Read the code</a>
      </div>
    </section>
    
    <section class="gated">
      <h2>What is gated</h2>
      <div class="manifest">
        <ul>
          <li>Live frontier-model calls
            <span class="note">Requires your own API keys (OpenAI, Anthropic, Google, or local via vLLM)</span>
          </li>
          <li>Live vision critique
            <span class="note">Requires multimodal API key + screenshot pipeline (Playwright or puppeteer-cluster)</span>
          </li>
          <li>Standalone npm packages for editor plugins
            <span class="note">Currently bundled; separate publish pending registry setup</span>
          </li>
          <li>Additional tokens
            <span class="note">Community submissions accepted; curation requires maintainer review</span>
          </li>
