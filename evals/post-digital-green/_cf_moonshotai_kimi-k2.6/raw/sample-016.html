AHD Artificial Human Design

A framework for evaluating generated interfaces against explicit design criteria. Not a generator. Not a copilot. A calibration tool for teams who need to know whether what shipped was considered or merely produced.

AI-generated sites have become a recognizable aesthetic: unearned confidence, approximately correct spacing, generic authority. The issue is not the tool but the absence of evaluation—no loop that checks work against intent.

AHD provides that loop. You write a brief, compile it to eval rules, and run generated candidates through a linter, a vision critic, and a harness that scores against your spec. The output is a verdict, not more variants.

One-liner evaluation bash 
$ ahd eval-live swiss-editorial \
  --brief briefs/landing.yml \
  --models <specs> \
  --n 10

What ships

  • Brief compiler (YAML spec → eval rules)
  • 28-rule linter with severity levels
  • Eval harness for batch scoring
  • Vision-critic scaffold (local inference path)
  • MCP server for editor integration
  • Editor plugins (VS Code, Zed; source in-repo)
  • Eight reference tokens as design anchors

What is gated

  • Live frontier-model calls — requires own API keys
  • Live vision critique — requires multimodal key + screenshot pipeline
  • Standalone npm packages for editor plugins
  • Additional tokens beyond the base eight

Gated items need external credentials or build steps. Core tooling runs offline.
