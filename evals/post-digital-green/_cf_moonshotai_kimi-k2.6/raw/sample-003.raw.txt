                <div class="manifest manifest-ships">
                    <h3>What ships</h3>
                    <ul>
                        <li>Brief compiler <span class="note">YAML → structured eval spec</span></li>
                        <li>28-rule linter <span class="note">typography, spacing, color, motion, accessibility constraints</span></li>
                        <li>Eval harness <span class="note">parallel execution, scoring, regression tracking</span></li>
                        <li>Vision-critic scaffold <span class="note">screenshot → structured critique pipeline (local inference supported)</span></li>
                        <li>MCP server <span class="note">Model Context Protocol integration for IDE embedding</span></li>
                        <li>Editor plugins <span class="note">VS Code, Zed; Vim/Neovim via LSP bridge</span></li>
                        <li>Eight tokens <span class="note">curated reference set with provenance documentation</span></li>
                    </ul>
                </div>
            </section>

            <section>
                <div class="manifest manifest-gated">
                    <h3>What is gated</h3>
                    <ul>

                        <li>Live vision critique <span class="note">requires multimodal key + screenshot pipeline (Playwright or similar)</span></li>
                        <li>Standalone npm packages for editor plugins <span class="note">pending registry automation; install from repo for now</span></li>
                        <li>Additional tokens <span class="note">license-cleared artwork sourcing in progress</span></li>
                    </ul>
                </div>
            </section>
