Artificial Human Design

AHD is a framework for evaluating design systems with rules, not taste. You write a brief. The compiler expands it into evaluable criteria. Models generate candidates. A linter and vision critic score against the brief. You get a ranked set with traceable scores, not a vibe check.

Built for teams who have already seen what un-evaluated generation produces and want to close the loop.

bash 
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

What ships

  • Brief compiler — YAML to structured eval criteria
  • 28-rule linter — typographic, spatial, and interaction rules
  • Eval harness — batch runner with deterministic seeding
  • Vision-critic scaffold — multimodal scoring pipeline, ready for your keys
  • MCP server — Model Context Protocol for IDE integration
  • Editor plugins — VS Code and Zed, source-installable today
  • Eight tokens — curated aesthetic priors, CC-BY-4.0

What is gated

  • Live frontier-model calls — requires your own API keys
  • Live vision critique — requires multimodal key + screenshot pipeline
  • Standalone npm packages for editor plugins — registry publish pending
  • Additional tokens — community contributions in review
