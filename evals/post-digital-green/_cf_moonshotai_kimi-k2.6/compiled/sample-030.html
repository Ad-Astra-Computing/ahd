ahd

artificial human design — a framework for evaluating generated interfaces

you have seen the slop. flat gradients, corporate memphis, three identical cards with sparkle icons. ahd does not explain why this happens. ahd gives you tools to measure it, compare it, and stop it.

the framework compiles a design brief into a structured eval, runs models against it, and scores the output against a rule set written by humans who have shipped real products.

run one eval:

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

this generates scored outputs, a rule-by-rule breakdown, and a trace you can inspect. the linter runs without api keys. the rest is gated behind what you already have.

what ships

  • brief compiler — yaml to structured eval with token substitution
  • 28-rule linter — static rules, no model calls, runs locally
  • eval harness — batch runner with variance analysis and trace logging
  • vision-critic scaffold — infrastructure for multimodal critique, ready to wire
  • mcp server — model context protocol server for editor integration
  • editor plugins — vscode and neovim configs, inline linting on generated code
  • eight tokens — curated design-language primitives, cc-by-4.0

what is gated

  • live frontier-model calls — needs api keys (openai, anthropic, google, etc)
  • live vision critique — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins — awaiting registry setup
  • additional tokens — community submissions under review
