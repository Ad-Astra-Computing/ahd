AHD v0.1.0 — artificial human design

framework for evaluating
generative design output

you have seen the slop. this is the linter.

AHD treats design as a testable artifact. brief in, rules enforced, scores out. no prompt engineering as substitute for taste.

the system compiles a creative brief into an eval harness, runs it against frontier models, and scores the output against a 28-rule lint suite. vision critique checks the rendered result. you get a number, a trace, and a fix list.

   brief.yml ──► compiler ──► harness ──┬──► model call ──► response
                                       │                    │
                                       └──► vision critic ◄─┘
                                                │
                                                ▼
                                           score + trace

the eval is one command. no ui, no ceremony.

$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

run it locally. read the trace. decide if the design holds.

what ships

  • brief compiler — yaml spec to typed eval plan
  • 28-rule linter — spacing, colour, typography, motion, surface
  • eval harness — parallel runner with deterministic seeding
  • vision-critic scaffold — multimodal scoring pipeline (bring your own endpoint)
  • MCP server — model context protocol for editor integration
  • editor plugins — vscode, neovim, zed (install from repo)
  • eight tokens — cc-by-4.0 design system seeds

what is gated

  • live frontier-model calls — needs api keys
  • live vision critique — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins — wip, install from source
  • additional tokens — in draft, not yet released
