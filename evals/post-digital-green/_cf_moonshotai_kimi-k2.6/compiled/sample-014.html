artificial human design

a framework for evaluating generative design systems. you already know the problem. this is one attempt at structural rigor instead of more slop.

AHD treats every design candidate as an artifact to be measured against a compiled brief, not a vibe to be approved. the framework separates what can be verified (layout rules, contrast ratios, grid adherence) from what requires judgment (taste, coherence, intent).

     brief.yml  →  [compiler]  →  AST
                              ↓
     tokens/    →  [linter]  →  violations + scores
                              ↓
     models     →  [harness]  →  ranked candidates
                              ↓
     screenshot →  [vision]   →  delta report

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

the command above runs ten candidates through the full pipeline for the swiss-editorial token set. results are scored and sorted. the top candidate is not automatically correct; it is the starting point for human review.

what ships

  • brief compiler — yaml to typed AST with constraint extraction
  • 28-rule linter — spatial, typographic, color, and motion rules
  • eval harness — parallel candidate generation with scoring
  • vision-critic scaffold — multimodal critique pipeline (bring your own key)
  • MCP server — model context protocol for editor integration
  • editor plugins — vscode and neovim (source-install for now)
  • eight tokens — curated prompt sets for common design patterns

what is gated

  • live frontier-model calls — needs API keys (openai, anthropic, google, etc)
  • live vision critique — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins — pending registry setup
  • additional tokens — held for quality threshold, not paywall

read the code — the repo includes the full linter, compiler, and harness. contributions under FSL-1.1-Apache-2.0.

no installation wizard. no dashboard. clone, configure keys, run the command above. the framework assumes you can read error messages.
