artificial human design

a framework for evaluating
generative design output

you have seen the slop. cheap gradients, purple-to-blue heroes, three identical cards with lucide icons in gradient tiles. the recognisable sheen of something made without taste or constraint.

AHD does not sell you AI-native speed. it ships a compiler, a linter, and an evaluation harness that treats design output as testable artefact. if the brief says "no gradients", the linter fails. if the vision critic detects corporate memphis, the score drops.

run the eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

the harness runs n generations against the compiled brief, scores each via the linter, and surfaces the three best with full violation logs. read the code.

what ships

  • brief compiler — yaml to typed constraint tree
  • 28-rule linter — spacing, colour, typography, motion, surface
  • eval harness — batch runner with scoring and logging
  • vision-critic scaffold — multimodal critique pipeline (local placeholder model included)
  • MCP server — model context protocol interface for editor integration
  • editor plugins — vscode and zed (workspace scripts, not standalone packages)
  • eight tokens — curated system prompts for consistent aesthetic direction

what is gated

  • live frontier-model calls — needs API keys (openai, anthropic, google, etc.)
  • live vision critique — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins — pending registry setup
  • additional tokens — gated on community contribution and review
