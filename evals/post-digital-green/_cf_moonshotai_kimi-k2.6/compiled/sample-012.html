AHD

artificial human design — version 0.1.0

you have seen the output. flat gradients, three equal cards, Trusted by in greyscale. the machines are not the problem; the evaluation is. AHD is a framework for specifying what design means, compiling that specification into tests, and running those tests against generative systems.

we do not sell productivity. we do not sell the future. we ship a linter, a harness, and a vocabulary. you bring the taste.

$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
brief.yml ──> [compiler] ──> token list │ ▼ candidate ──> [linter/28] ──> pass/fail + trace │ ▼ screenshot ──> [vision-critic] ──> delta report

What ships

  • brief compiler — yaml to typed token sequence
  • 28-rule linter — spatial, typographic, colour, and motion constraints
  • eval harness — batch runner with deterministic seeding
  • vision-critic scaffold — multimodal comparison pipeline (code, not endpoint)
  • MCP server — model context protocol for editor integration
  • editor plugins — vscode and neovim bindings (source in-repo, not packaged)
  • eight tokens — base vocabulary for surface description

What is gated

  • live frontier-model calls — needs API keys, not included
  • live vision critique — needs multimodal key + screenshot pipeline setup
  • standalone npm packages for the editor plugins — still source-only
  • additional tokens — waiting on corpus validation
