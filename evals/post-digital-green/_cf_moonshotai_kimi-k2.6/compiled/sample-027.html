AHD

artificial human design — a framework for evaluating generative design systems

you have seen the output. flat color fields, identical radius curves, placeholder smiling figures. the tools are fast; the results are indistinguishable. slop is not a supply problem. it is an evaluation problem.

AHD treats design as a testable interface between intent and execution. a brief compiles to constraints. a linter checks those constraints against output. a vision critic checks the output against human perception. nothing ships without passing.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

run this against your own briefs. the harness is deterministic. the models are swappable. the rules are versioned.

What ships

  • brief compiler — yaml to constraint graph
  • 28-rule linter — spacing, type scale, color contrast, motion policy, forbidden pattern detection
  • eval harness — batch runner with retry logic and result caching
  • vision-critic scaffold — passes screenshots to multimodal evaluator, returns scored checklist
  • MCP server — exposes linter and harness as model-callable tools
  • editor plugins — vscode and neovim, inline lint while you edit briefs
  • eight tokens — curated starting constraints for common design problems

What is gated

  • live frontier-model calls — needs API keys, not included
  • live vision critique — needs multimodal key + screenshot pipeline
  • standalone npm packages for the editor plugins — still in repo, not published
  • additional tokens — gated on community contribution review
