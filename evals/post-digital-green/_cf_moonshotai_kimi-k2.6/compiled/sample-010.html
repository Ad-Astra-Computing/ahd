AHD

artificial human design — a framework for evaluating generated interfaces

you have seen the output. flat gradients, rounded corners, three equal cards, a "trusted by" strip of logos nobody recognises. we do not need to describe the problem. we need to measure it.

AHD is a toolchain for compiling design briefs, linting outputs against explicit constraints, and running model evaluations with reproducible scoring. it is for teams who want to know why a layout fails, not just that it fails.

# run evaluation against a live model with structured brief
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

the command compiles the brief, runs the linter, calls the model <n> times, and scores each output against the same rule set. no manual review required for the first cut.

What ships

  • brief compiler — yaml to structured prompt with token budgeting
  • 28-rule linter — accessibility, layout, typography, forbidden patterns
  • eval harness — parallel model execution with timeout and retry
  • vision-critic scaffold — screenshot pipeline ready for multimodal review
  • MCP server — model context protocol for editor integration
  • editor plugins — vim, emacs, vscode (extension source included)
  • eight tokens — curated design system primitives, versioned

What is gated

  • live frontier-model calls — needs API keys, not included
  • live vision critique — needs multimodal key + screenshot pipeline setup
  • standalone npm packages for the editor plugins — not yet published
  • additional tokens — gated on contributor review
