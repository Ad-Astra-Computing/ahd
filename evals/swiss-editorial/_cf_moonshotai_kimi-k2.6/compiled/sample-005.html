Artificial Human Design

Discipline
not slop

Most AI-generated sites look the same because the process tolerates default choices. AHD is a framework for systematic evaluation. It compiles briefs, lints output against explicit rules, and scores results with vision models. The goal is not more output. It is better decisions.

bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • MCP server
  • Editor plugins
  • Eight tokens

What is gated

  • Live frontier-model calls (needs API keys)
  • Live vision critique (needs multimodal key + screenshot pipeline)
  • Standalone npm packages for the editor plugins
  • Additional tokens

The framework is opinionated. The rules are explicit. The scoring is calibrated.
