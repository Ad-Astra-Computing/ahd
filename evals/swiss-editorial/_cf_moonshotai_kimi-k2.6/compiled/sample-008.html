A framework for evaluating design with verifiable constraints. Not a generator. A benchmark and a linter for work that claims to be designed.

The thesis is simple: most AI-generated interfaces fail basic rules of typography, measure, colour contrast, and grid discipline. AHD documents those rules. Then it checks if anyone followed them.

Run the eval

A single command. No install script. No daemon.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

The harness runs your prompt against n models. Each output is linted against the brief. Vision critique scores the result against a screenshot. You get a markdown report with pass/fail and deltas.

What ships

  • Brief compiler — YAML to structured evaluation plan
  • 28-rule linter — typography, colour, space, and motion constraints
  • Eval harness — headless browser + model runner
  • Vision-critic scaffold — multimodal scoring pipeline
  • MCP server — plug into any editor
  • Editor plugins — VS Code, Zed, Neovim
  • Eight tokens — design-system seeds with full briefs

What is gated

  • Live frontier-model calls — needs API keys
  • Live vision critique — needs multimodal key + screenshot pipeline
  • Standalone npm packages for the editor plugins
  • Additional tokens — awaiting community contribution
