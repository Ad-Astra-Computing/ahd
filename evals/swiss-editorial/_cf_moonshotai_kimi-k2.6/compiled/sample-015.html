AHD

Artificial Human Design. A framework for evaluating design output from generative systems. Not a critique of tools. A method for keeping them honest.

You have seen the slop. You do not need another lecture. You need something that runs: a compiler, a linter, an eval harness, and a vocabulary of tokens that constrain rather than expand. 

# ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

Available now

  • Brief compiler
  • 28-rule linter
  • Eval harness
  • Vision-critic scaffold
  • MCP server
  • Editor plugins
  • Eight tokens

What is gated

  • Live frontier-model calls (needs API keys)
  • Live vision critique (needs multimodal key + screenshot pipeline)
  • Standalone npm packages for the editor plugins
  • Additional tokens

Gated items require external resources. The core framework runs offline. No accounts. No telemetry.
