AHD

Artificial Human Design is a framework for evaluating design output from language models. It treats generated interfaces as material to be measured, not magic to be marketed.

The thesis is simple: most AI-generated sites share the same failure modes. Centered heroes. Gradient text. Three equal cards. AHD documents these patterns, compiles briefs into enforceable specifications, and runs evals that return scores instead of opinions.

You do not need another tool that promises to replace your judgment. You need a way to keep that judgment consistent across models, prompts, and versions.

Run an eval

This command compiles the brief, lints the output against 28 rules, and scores ten generations. The vision critic requires a multimodal key and a screenshot pipeline.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Replace <specs> with model identifiers. The harness handles concurrency, timeout, and result collation.
