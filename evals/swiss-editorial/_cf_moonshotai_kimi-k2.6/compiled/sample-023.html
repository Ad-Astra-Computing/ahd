A framework for evaluating design generated by language models. Compile a brief. Lint the output. Run the eval. Score what ships.

28 Rules 8 Tokens

Run the eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Outputs a scored report. Passes fail loud. No gatekeeping.

What ships

  • Brief compiler — validates intent against forbidden patterns
  • 28-rule linter — structural, typographic, and motion audits
  • Eval harness — runs models against compiled briefs
  • Vision-critic scaffold — multimodal scoring pipeline
  • MCP server — model context protocol for editor integration
  • Editor plugins — VS Code and Zed extensions
  • Eight tokens — curated design system primitives

What is gated

  • Live frontier-model calls — needs API keys
  • Live vision critique — needs multimodal key plus screenshot pipeline
  • Standalone npm packages for the editor plugins
  • Additional tokens
