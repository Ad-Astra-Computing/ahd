AHD.

No more slop.

AHD is a framework for evaluating AI-generated design. It compiles briefs into testable rules, runs models against them, and scores the output. You read the rules before you read the code. Read the code.

Run the eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • Brief compiler
  • 28-rule linter
  • Eval harness
  • Vision-critic scaffold
  • MCP server
  • Editor plugins
  • Eight tokens

What is gated

  • Live frontier-model calls needs API keys
  • Live vision critique needs multimodal key + screenshot pipeline
  • Standalone npm packages editor plugins
  • Additional tokens
