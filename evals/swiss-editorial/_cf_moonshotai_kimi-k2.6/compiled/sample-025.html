Framework for evaluated design

AHD.

Most AI interfaces produce slop. AHD evaluates every output against a compiled design brief before it reaches a human. The framework ships as a compiler, a linter, and a harness you run yourself. No cloud dependency. No model lock-in.

Design is not generation. It is constraint.

Run the eval

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • Brief compiler
  • 28-rule linter
  • Eval harness
  • Vision-critic scaffold
  • MCP server
  • Editor plugins
