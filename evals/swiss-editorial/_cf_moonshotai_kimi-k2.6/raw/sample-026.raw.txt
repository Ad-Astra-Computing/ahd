    <div class="container">
      <div class="section-label">Thesis</div>
      <p>Most generated design fails at the level of system: inconsistent spacing hierarchies, unresolved contrast relationships, type pairings that work in isolation and collapse at scale. Current tooling optimises for first-glance coherence, not structural integrity.</p>
      <p>AHD treats a design as a program with invariants. The brief compiler turns your intent into constraints. The linter checks 28 rules against every candidate. The eval harness runs batches against multiple models. The vision-critic scaffold verifies render output against the source tokens. Everything is inspectable, everything is versioned, nothing is assumed correct because it looks polished.</p>
    </div>
  </section>

    <div class="container">

            <li>Brief compiler (YAML design constraint DSL)</li>
            <li>28-rule linter with severity levels</li>
            <li>Eval harness with batch scoring and regression tracking</li>
            <li>Vision-critic scaffold (self-hosted multimodal pipeline ready)</li>
            <li>MCP server for IDE integration</li>
            <li>Editor plugins (Vim, VS Code, Zed — install from repo)</li>
            <li>Eight base tokens covering spacing, type scale, and colour systems</li>
          </ul>
        </div>
        
        <div class="manifest gated">

            <li>Standalone npm packages for editor plugins: in progress, install from source for now</li>
