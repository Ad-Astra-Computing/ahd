Artificial Human Design

A framework for disciplined evaluation of generative design. You write a brief. The system compiles it, lints against human-curated rules, and runs model outputs through a repeatable harness with vision critique.

AHD does not generate. It does not prompt-engineer its way to beauty. It establishes whether a given model, at a given moment, can produce work that meets criteria you defined in advance.

The output is a verdict, not a mockup. The verdict is reproducible because the rules are explicit, versioned, and inspectable. 

$ ahd eval-live swiss-editorial \
  --brief briefs/landing.yml \
  --models <specs> \
  --n 10

What ships

  • Brief compiler — YAML schema to typed evaluation spec
  • 28-rule linter — coverage, proportion, negative-space, type-scale, and 24 others
  • Eval harness — parallel generation, scoring, and regression detection
  • Vision-critic scaffold — multimodal critique pipeline with pluggable backends
  • MCP server — Model Context Protocol integration for editor/IDE access
  • Editor plugins — Vim, Neovim, VS Code (extension hosted; install from source)
  • Eight tokens — design vocabulary for brief authorship, CC-BY-4.0

What is gated

  • Live frontier-model calls — requires your own API keys
  • Live vision critique — requires multimodal key plus screenshot pipeline (Playwright, headless browser)
  • Standalone npm packages for the editor plugins — pending registry setup
  • Additional tokens — 34 in curation; release gated on community review
