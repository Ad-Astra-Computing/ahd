    <h1>Artificial Human Design</h1>
    <p class="tagline">A framework for evaluating design output, not generating it.</p>
    
    <div class="problem">
      <p>The slop problem is not that AI makes design. It is that no one has built the tooling to say whether the output is any good. Teams ship unexamined synthesis because the alternative is manual review at a scale that breaks process.</p>
      <p>AHD provides the eval layer: a brief compiler, a rule-based linter, and a harness for running multi-model comparison against defined constraints. You write the brief. The framework enforces it.</p>
    </div>
    
    <div class="code-block">
      <div class="code-header">bash</div>
      <pre><code><span class="arg">ahd</span> <span class="flag">eval-live</span> <span class="value">swiss-editorial</span> <span class="flag">--brief</span> <span class="value">briefs/landing.yml</span> <span class="flag">--models</span> <span class="param">&lt;specs&gt;</span> <span class="flag">--n</span> <span class="value">10</span></code></pre>
    </div>
    
    <div class="manifest-grid">
      <section class="manifest manifest-ships">
        <h2>What ships</h2>
        <ul>
          <li><strong>Brief compiler</strong> — YAML/JSON schema with constraint validation</li>
          <li><strong>28-rule linter</strong> — typographic and spatial heuristics, no model calls required</li>
          <li><strong>Eval harness</strong> — batched generation, comparative scoring, reproducible seeds</li>
          <li><strong>Vision-critic scaffold</strong> — protocol and prompt templates for multimodal review</li>
          <li><strong>MCP server</strong> — Model Context Protocol integration for IDE embedding</li>
          <li><strong>Editor plugins</strong> — VS Code, Zed, NeoVim (source-available, manual install)</li>
          <li><strong>Eight tokens</strong> — base design-tokens collection, versioned</li>
        </ul>
      </section>
      
      <section class="manifest manifest-gated">
        <h2>What is gated</h2>
        <ul>
          <li><strong>Live frontier-model calls</strong> <span class="note">Needs API keys. Eval defaults to local linting without them.</span></li>
          <li><strong>Live vision critique</strong> <span class="note">Needs multimodal key + screenshot pipeline. Scaffold works with static assets.</span></li>
          <li><strong>Standalone npm packages</strong> <span class="note">for editor plugins. Source builds today; registry publish pending.</span></li>
          <li><strong>Additional tokens</strong> <span class="note">Beyond the eight base sets. Community contributions in review.</span></li>
        </ul>
      </section>
