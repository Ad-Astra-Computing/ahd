Artificial Human Design

A framework for evaluating whether a design system deserves the name. Not a generator. Not a critique of AI in the abstract. A specific, repeatable protocol for the moment when a working designer has to decide: does this output hold up, or is it slop?

Run it
bash 
ahd eval-live swiss-editorial \
  --brief briefs/landing.yml \
  --models <specs> \
  --n 10

This runs ten candidates against a compiled brief, scores each through the linter, and surfaces the top two for human review. The vision-critic scaffold is callable but gated on your own multimodal key. Nothing phones home.

What is gated

  • Live frontier-model calls needs API keys
  • Live vision critique needs multimodal key + screenshot pipeline
  • Standalone npm packages for the editor plugins pending registry
  • Additional tokens external curators

Gated items are gated on external resources, not on licensing or payment. The framework itself is unencumbered.
