Artificial Human Design

A framework for evaluating design quality without outsourcing judgment to models that cannot see.

You have already seen the slop. You do not need another essay on why it is bad. AHD is a toolchain for designers and engineers who want structured critique, reproducible evaluation, and a way to keep humans in the loop without pretending the loop does not exist. It is not a generator. It is a mirror.

bash 
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • Brief compiler — transforms YAML briefs into structured evaluation contexts
  • 28-rule linter — design heuristics derived from actual human critique practice
  • Eval harness — batch runner with deterministic seeding and result aggregation
  • Vision-critic scaffold — plumbing for multimodal critique, runs locally with your own keys
  • MCP server — Model Context Protocol server for integration with compatible editors
  • Editor plugins — VS Code and Neovim extensions (source in-repo, build from source today)
  • Eight tokens — curated design tokens with human-written rationale per value

What is gated

  • Live frontier-model calls — needs your own API keys (OpenAI, Anthropic, or compatible)
  • Live vision critique — needs multimodal key + working screenshot pipeline (Playwright, Puppeteer, or manual)
  • Standalone npm packages for the editor plugins — publish pipeline blocked on registry access
  • Additional tokens — blocked on community submission + curation cycle
Nothing here requires a subscription to AHD. The gated items need your own infrastructure or patience. The framework itself is designed to degrade gracefully: run the linter offline, run the harness with local models, skip vision critique entirely.
