Artificial Human Design

A framework for evaluating design without outsourcing judgment.

AHD treats generative-output quality as a measurable property. The framework compiles briefs into structured evaluation prompts, runs them against configurable model sets, and surfaces critique through a linter-style interface. If you are already filtering AI-generated work by hand, this systematizes the process. Read the code →

github.com/artificialhumandesign/ahd

What it does

Brief compiler
YAML + frontmatter into structured evaluation prompts with explicit constraints, references, and heuristics.
Linter
28 rules covering alignment, hierarchy, typography scale, color relationships, motion ethics, and accessibility basics.
Eval harness
Parallel execution against multiple models with voting and confidence scoring.
Vision critic
Multimodal pipeline for screenshot-to-critique when you need to evaluate rendered output, not just code.
# Run a live evaluation against 10 model configurations
ahd eval-live swiss-editorial \
  --brief briefs/landing.yml \
  --models <specs> \
  --n 10
