Artificial Human Design v0.8.2

A framework for evaluating design before it ships. Not for generating more. For catching what generators miss.

The Thesis

You have already seen the problem. Sites with identical tension curves, identical padding logic, identical suggestions for "modern" typography. The generators are fast; the output is coherent; the coherence is the flaw.

AHD does not add another model. It adds structure: a compiler for design briefs, a linter with explicit rules, a harness for running comparative evaluation, and a scaffolding for human-in-the-loop critique. Use it against generated output, against your own work, or against a contractor deliverable.

Run an Eval

bash 
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

eval-live compiles the brief, runs the linter against each candidate, scores against the vision-critic scaffold, and emits a ranked report. The --models <specs> flag accepts any OpenAI-compatible endpoint or local server via the MCP layer.

What Ships

Now
Brief compiler
YAML-to-structured-design-spec with inheritance and override. Validates constraints before any model sees them.
Now
28-rule linter
Detects spacing violations, hierarchy collapse, visual rhyme without meaning, and other patterns that pass visual inspection but fail design intent.
Now
Eval harness
Parallel runner for A/B and n-ary comparison. Handles scoring aggregation, tie-break rules, and reproducible seeding.
Now
Vision-critic scaffold
Prompt engineering and response-parsing layer for multimodal critique. Includes rubric templates and confidence calibration.
Now
MCP server
Model Context Protocol implementation for IDE integration. Accepts tool calls from any MCP client.
Now
Editor plugins
VS Code and Vim extensions for inline linting and brief preview. Installs from source today; packaged distribution pending.
Now
Eight tokens
Curated design-token sets for systematic evaluation: Swiss, Brutalist, Editorial, Product, Dense, Aerial, Warm, and Neutral.

What Is Gated

External
Live frontier-model calls
Requires your own API keys. No proxy, no bundled credits. AHD orchestrates; you provide the endpoint.
External
Live vision critique
Needs multimodal model key plus screenshot pipeline (Puppeteer or Playwright). The scaffold is yours; the runtime is not.
Pending
Standalone npm packages for editor plugins
Install from source now. Pre-built packages gated on CI migration and registry signing.
Pending
Additional tokens
Six more token sets in review. Released when they pass the same linting threshold we apply to generated work.
