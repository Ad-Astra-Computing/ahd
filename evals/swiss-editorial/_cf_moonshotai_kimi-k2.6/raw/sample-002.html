AHD — Artificial Human Design

A framework for evaluating design outputs against explicit, versioned criteria. It does not generate. It checks, scores, and records what passed, what failed, and why.

The problem with most AI-adjacent design tools is not the model. It is the absence of an eval loop: no linter, no regression test, no way to know whether yesterday's fix broke last week's layout rule. AHD is that loop.

Run a live evaluation
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • 01 Brief compiler YAML to typed evaluation spec
  • 02 28-rule linter Spacing, type scale, color contrast, motion
  • 03 Eval harness Batch runner with deterministic seeding
  • 04 Vision-critic scaffold Structured prompt templates for multimodal review
  • 05 MCP server Model Context Protocol for IDE integration
  • 06 Editor plugins VS Code, Zed (source in repo; build from source)
  • 07 Eight tokens Base vocabulary for layout and component classification

What is gated

  • — Live frontier-model calls Requires own API keys
  • — Live vision critique Needs multimodal key + screenshot pipeline
  • — Standalone npm packages Editor plugins; build from source today
  • — Additional tokens Domain-specific vocabularies pending
