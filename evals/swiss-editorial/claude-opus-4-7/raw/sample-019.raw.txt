  <h1>A framework for not shipping slop.</h1>

  <p class="lede">
    AHD is a toolchain for evaluating whether a generated interface is actually
    <b>designed</b> — against a brief, against a rule set, against a live panel
    of models critiquing each other's output.
  </p>

  <p class="thesis">
    You already know the pattern. Centred hero, pill badge, three equal cards,
    a shimmer somewhere. The problem isn't the models; it's that nobody wrote
    down what good looks like in a format a model can be graded against. AHD
    does that, and then runs the grading.
  </p>

  <div class="cta-row">
    <a href="https://github.com/ahd/ahd">read the code → github.com/ahd/ahd</a>
    <a href="https://code.ahd.dev/ahd/ahd">forgejo mirror</a>
    <span class="note">// MIT-signed commits, reproducible evals</span>
  </div>

  <div class="rule"></div>

  <p style="margin-bottom:14px;">
    The one-liner below runs a live eval of a Swiss editorial brief across
    <i>n</i> model specs and returns a ranked, linter-scored, vision-critiqued
    set of candidates.
  </p>

  <div class="term" role="region" aria-label="terminal">
    <div class="term-head"><span>~/ahd</span><span class="lang">bash</span></div>
    <div class="term-body">
<pre><span class="prompt">$</span> <span class="cmd">ahd eval-live swiss-editorial</span> <span class="flag">--brief</span> <span class="arg">briefs/landing.yml</span> <span class="flag">--models</span> <span class="arg">&lt;specs&gt;</span> <span class="flag">--n</span> <span class="arg">10</span>
<span class="comment">→ compiling brief ·· 28 rules loaded ·· dispatching to panel ·· vision critic: scaffold</span></pre>
    </div>

  <section class="manifest ships">
    <h2>What ships <span class="tag">today</span></h2>
    <ol>
      <li><div><b>Brief compiler.</b> YAML → typed constraints the linter and eval harness both consume.</div></li>
      <li><div><b>28-rule linter.</b> Static checks for the slop patterns nobody bothers to name: gradient text, centred-hero-plus-pill, three equal cards, emoji bullets, Corporate Memphis, and 23 more.</div></li>
      <li><div><b>Eval harness.</b> Panel-of-models runner with deterministic seeds, per-rule scoring, and diffable output.</div></li>
      <li><div><b>Vision-critic scaffold.</b> The rendering pipeline, prompt templates, and rubric — wired for a multimodal model to plug into.</div></li>
      <li><div><b>MCP server.</b> Exposes the linter and eval harness to any MCP-speaking editor or agent.</div></li>
      <li><div><b>Editor plugins.</b> In-repo integrations for VS Code, Zed, and Neovim. Run from source.</div></li>
      <li><div><b>Eight tokens.</b> A minimal, opinionated Swiss-editorial token set: type scale, measure, rule weights, two ink values, one accent.</div></li>
    </ol>
  </section>

  <section class="manifest gated">
    <h2>What is gated <span class="tag">external</span></h2>
    <ol>
      <li><div><b>Live frontier-model calls.</b><span class="req">requires: your own API keys (OpenAI, Anthropic, Google, or local)</span></div></li>
      <li><div><b>Live vision critique.</b><span class="req">requires: multimodal key + a working screenshot pipeline (Playwright recommended)</span></div></li>
      <li><div><b>Standalone npm packages for the editor plugins.</b><span class="req">requires: registry publication; currently source-only</span></div></li>
      <li><div><b>Additional tokens.</b><span class="req">requires: upstream design work beyond the eight; roadmapped, not promised</span></div></li>
    </ol>
  </section>
