AHD·artificial human design
v0.4.1  /  2026-04-22

The slop is the product. Treat it as such.

AHD is a small, opinionated toolchain for designing with frontier models without inheriting their defaults. It assumes you have already noticed the sameness, the centred hero, the pill badge, the gradient on the word that shall not be named.

It does not lecture. It compiles a brief, runs a 28-rule lint over what comes back, and scores ten variants per model against an editorial reference. You read the diff. You keep what is yours.

bash$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

— runs the live eval against your spec set, returns a ranked diff and a lint report.

What ships

today / in this repo / no key required
  • brief compilerYAML brief → constrained prompt with editorial guard-rails.
  • 28-rule linterCatches the canonical tells: gradient hero, three equal cards, badge stack, blob, shimmer, et al.
  • eval harnessReproducible n-of-k runs across model specs, with deterministic seeding and a JSON report.
  • vision-critic scaffoldLocal stub that defines the critique schema and runs a deterministic mock for tests.
  • MCP serverExposes the compiler, linter, and harness as Model Context Protocol tools.
  • editor pluginsSource for the Zed, Neovim, and VS Code integrations — load locally from this repo.
  • eight tokensA starter set: ink, paper, rule, accent, muted, mono, serif, measure. CC-BY-4.0.

What is gated

requires external resources / not in this repo
  • live model callsFrontier-model evaluation needs your own API keys; AHD does not ship credentials.
  • live vision critiqueRequires a multimodal key plus a screenshot pipeline (headless browser, storage).
  • npm packagesStandalone, versioned editor-plugin distributions are not yet published to a registry.
  • additional tokensExtended palettes, type scales, and motion tokens are tracked separately and released on cadence.

AHD is not a framework you adopt. It is a set of small, legible programs you run against the output you were going to ship anyway. If the linter is wrong, the rules are 280 lines of TypeScript; rewrite them.
