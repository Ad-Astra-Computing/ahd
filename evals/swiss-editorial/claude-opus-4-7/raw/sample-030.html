A toolkit for designers who have noticed the slop.

You have seen the same landing page forty times this month. Centred stack, pill badge, two buttons, three equal feature cards, a gradient somewhere on the word it is selling. AHD is the counter-infrastructure: a brief compiler, a linter that knows what a Swiss editorial layout actually is, and an eval harness that runs the prompt against real models and grades the output.

AHD is not a generator. It is the scaffolding around one — the part that decides whether what came out is any good, and tells you which of twelve candidate compositions is the one a human would have chosen. The code is open; the evaluator runs locally; the harness is the point.

~/ahd · bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Runs the brief against N=10 samples per model, lints each output with the 28-rule checker, then scores against the vision-critic scaffold. Writes a diff-able report to ./runs/.

thesis The problem is not that models cannot draw. The problem is that nothing is grading them on taste. AHD is that grader, and it is opinionated on purpose.

§01 What ships — today, in this repo

01
Brief compiler.YAML → structured design brief with typed constraints, grid, voice, and reference corpus.
02
28-rule linter.Checks hierarchy, optical alignment, rhythm, measure, and the usual AI tells. Fails loudly.
03
Eval harness.Deterministic runner, seeded sampling, side-by-side diff reports, JSON + HTML output.
04
Vision-critic scaffold.Pluggable interface; ships with a local heuristic critic and stubs for multimodal backends.
05
MCP server.Exposes brief, lint, and eval as tools for any MCP-compatible client.
06
Editor plugins.In-tree sources for VS Code and Zed. Sideload today; packaged tomorrow.
07
Eight tokens.A deliberately small starter palette: two greyscales, one paper, one ink, three accents, one signal.

§02 What is gated — blocked on external resources

g1
Live frontier-model calls.Needs your own API keys. The harness runs; the remote inference does not, until you supply them.
g2
Live vision critique.Needs a multimodal key and a screenshot pipeline (Playwright + a GPU worker is the reference path).
g3
Standalone npm packages for the editor plugins.Publishing pending; the in-tree sources are the canonical artefact for now.
g4
Additional tokens.The extended set (type scales, motion, density) ships when the vision critic can grade them without cheating.
