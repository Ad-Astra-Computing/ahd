    <p class="sec-num">§00 — premise</p>
    <h1>An evaluator for design <em>that has stopped trying.</em></h1>

    <p class="lede">You have seen the sites. Same hero, same gradient, same three
      cards, same shimmer. AHD is the harness that names what's wrong, runs
      the same brief through several models, and grades the output against a
      Swiss-editorial rubric you can read.</p>

    <p>It is not a generator. It is the thing the generators should have been
      graded against before they shipped.</p>

    <div class="meta-row">
      <span><b>v0.4.0</b> · 2026-04</span>
      <span>licence <b>FSL-1.1-Apache-2.0</b></span>
      <span>repo <a href="https://github.com/ahd/ahd">github.com/ahd/ahd</a> · <a href="https://forge.ahd.tools/ahd/ahd">forgejo mirror</a></span>
    </div>

    <p class="sec-num">§01 — run it</p>
    <div class="term" role="region" aria-label="bash command">
      <span class="tag">bash</span>
<pre><span class="pr">$</span> ahd eval-live swiss-editorial <span class="fl">--brief</span> <span class="arg">briefs/landing.yml</span> <span class="fl">--models</span> <span class="arg">&lt;specs&gt;</span> <span class="fl">-n</span> <span class="arg">10</span></pre>
    </div>
    <p class="caption">One brief, ten generations per model, scored by 28 rules
      plus a vision pass. Produces a diff against the rubric, not a vibe.</p>

    <section class="manifest" id="manifest">
      <p class="sec-num" style="margin-top:6px">§02 — manifest</p>
      <h2>What ships</h2>
      <p class="intro">In the repo today. No keys, no waitlist, no signup.
        Clone, install, run against local fixtures.</p>
      <ol class="items">
        <li><div><b>Brief compiler.</b><span class="note">YAML brief → typed
          intermediate the rubric and the models both consume.</span></div></li>
        <li><div><b>28-rule linter.</b><span class="note">Static checks for
          the failure modes you already recognise: stacked CTAs, gradient AI,
          three-card grid, shimmer, Memphis blobs.</span></div></li>
        <li><div><b>Eval harness.</b><span class="note">Deterministic runner
          with seeds, n-of-k sampling, and a JSONL report format.</span></div></li>
        <li><div><b>Vision-critic scaffold.</b><span class="note">Pluggable
          interface plus a fixture-mode critic that runs offline.</span></div></li>
        <li><div><b>MCP server.</b><span class="note">Exposes brief, rubric,
          and lint to any MCP-aware client.</span></div></li>
        <li><div><b>Editor plugins.</b><span class="note">In-tree sources for
          VS Code and Zed; lint-on-save against the 28 rules.</span></div></li>
        <li><div><b>Eight tokens.</b><span class="note">The base editorial
          set: ink, paper, rule, accent, muted, term-bg, term-fg, term-dim.</span></div></li>
      </ol>
    </section>

    <section class="manifest gated">
      <h2>What is gated</h2>
      <p class="intro">Honest about the seams. These need something AHD
        cannot ship for you.</p>
      <ol class="items">
        <li><div><b>Live frontier-model calls.</b><span class="note">Needs
          your API keys. The harness runs against fixtures without them.</span></div></li>
        <li><div><b>Live vision critique.</b><span class="note">Needs a
          multimodal key plus a working screenshot pipeline (Playwright
          or equivalent).</span></div></li>
        <li><div><b>Standalone npm packages for the editor plugins.</b>
          <span class="note">Sources are in-tree; published packages are
          pending registry sign-off.</span></div></li>
        <li><div><b>Additional tokens.</b><span class="note">Beyond the
          eight, expanded scales (type, space, motion) land as the rubric
          earns them.</span></div></li>
      </ol>
    </section>
