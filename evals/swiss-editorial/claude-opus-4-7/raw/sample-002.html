You already know what slop looks like. AHD is the framework that treats it as a measurable defect.

AHD is a toolchain for Artificial Human Design: a brief compiler, a rule-based linter, and a live evaluation harness that scores generated layouts against a named tradition — Swiss editorial, brutalist print, whatever the brief declares — instead of against vibes.

No auto-play hero video. No "AI copilot that designs for you." One command runs the eval, you read the report, you decide whether the model earned the pixel.

§01 What ships

In the repository today, installable, no keys required.

01Brief compiler
YAML in, a typed intermediate representation out. Declares tradition, grid, type scale, and negative constraints as first-class fields.
0228-rule linter
Static checks against the compiled brief — measure consistency, baseline alignment, density budget, dead-centre hero detection, gradient-on-the-word-AI detection, and twenty-three more.
03Eval harness
Runs n renders per model, applies the linter, produces a per-run HTML report with diffs. Fully local. Deterministic with a seed.
04Vision-critic scaffold
The prompt templates, rubric, and IO contract for a multimodal critic. Wire your own key in.
05MCP server
Exposes the compiler, linter, and harness to any MCP-aware client. One transport, one schema.
06Editor plugins
Neovim, VS Code, Zed. Inline lint results on the IR. Jump-to-rule on any failure.
07Eight tokens
The opinionated starter palette: two serifs, one mono, four greys, one accent. Enough to render a credible Swiss-editorial page and nothing more.

§02 What is gated

What AHD cannot ship on its own — and why.

01Live frontier-model calls
Needs your API keys. AHD will not bundle or proxy frontier inference. Set AHD_OPENAI_KEY, AHD_ANTHROPIC_KEY, etc.
02Live vision critique
Needs a multimodal key plus a screenshot pipeline (Playwright or a remote renderer). The scaffold is in-repo; the runtime is yours.
03Standalone npm packages for the editor plugins
Today the plugins live inside the monorepo. Splitting them into published packages is tracked but unreleased.
04Additional tokens
Beyond the core eight. Brutalist, late-modernist, and newsprint sets exist in draft; they land when the linter rules that depend on them are cut.

# note: the gating is the point. AHD is a framework, not a hosted service.
