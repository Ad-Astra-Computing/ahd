AHD. Artificial Human Design
v0.4 · 2026-04

A framework, not a lecture

The slop is measurable. So measure it.

You have seen the sites. Generic hero, five features in a row, a footer that could belong to any SaaS on earth. AHD is a toolchain for treating that output as a failure mode rather than a style — a brief compiler, a rule linter, and a live eval harness that runs the same prompt across models and grades the result against a written brief.

Nothing here replaces taste. The point is to make taste legible to a process, so that when a model produces another centred stack with a pill badge and two CTAs, the linter says so, the harness logs it, and the diff is in the PR instead of in a screenshot quote-tweet.

Read the code on GitHub→ mirror: forgejo.ahd.dev/ahd

Run the eval

~/ahdbash
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Ten generations per model, scored against the brief, linted against the 28 rules, critiqued by vision when a multimodal key is present.

What ships

okbrief compiler
YAML → structured constraints the generator and the linter both consume.
ok28-rule linter
Rejects the known slop patterns: pill-badge hero, equal-thirds cards, gradient-on-"AI", Trusted-by strips, the canonical 4-col footer, and twenty-three more.
okeval harness
Runs N generations per model against a brief, stores outputs, diffs rule violations, produces a markdown scorecard.
okvision-critic scaffold
Headless render, screenshot capture, prompt template, structured rubric. Plug in your own multimodal model.
okMCP server
Exposes compiler, linter and harness as tools for any MCP-speaking editor or agent.
okeditor plugins
Zed and Neovim. Inline lint, brief-in-buffer, one-key re-eval. In-tree today.
okeight tokens
Type scale, rule weights, paper, ink, accent, muted, terminal ink, terminal dim. Enough to render this page.

What is gated

extlive frontier-model calls
Needs your API keys. AHD does not proxy, does not resell, does not cache. BYO provider.
extlive vision critique
Needs a multimodal key and a working screenshot pipeline (Playwright + fonts installed). Scaffold is in the box; the call is not.
exteditor plugins as npm
Standalone packages are planned. Today the plugins live in the monorepo and are installed from source.
extadditional tokens
Expanded palettes, density scales, mono pairings. Arriving as CC-BY packs; not part of v0.4.
