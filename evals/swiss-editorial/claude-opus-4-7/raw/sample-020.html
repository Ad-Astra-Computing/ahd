AHD/Artificial Human Design
command ships gated

A framework for design that doesn't look like every other prompted website this month.

You already know the pattern. Centred hero, pill badge, two CTAs, three equal cards, a purple-to-blue wash, a shimmer. AHD treats that output as a measurable regression, not a vibe.

It is a brief compiler, a linter, and an eval harness. You write a brief, the models draft against it, the harness scores drafts against a rubric grounded in Swiss editorial practice, and you read the diff. No lecture. A loop.

the one-liner

Run the live eval against the landing brief, ten drafts per model, in a single call. Results land as a static report you can grep.

bashahd · 0.4.2$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# writes ./out/<run-id>/{drafts,scores,diff.html}
Read the code on GitHub → or the Forgejo mirror

AHD does not generate a website for you. It generates a rubric, forces drafts through it, and shows you where each one fails. The output is legibility, not velocity.
