  <div class="kicker">v0.3 · 2026-04</div>
  <h1>A design system that <em>evaluates</em> its own output before you do.</h1>
  <p class="lede">You have already noticed the pattern. The purple gradient. The three cards. The pill badge above the stacked CTAs. Models producing layouts that look like each other because they were trained on each other.</p>
  <p class="lede">AHD is the operating response: a brief compiler, a linter that encodes the 28 bad habits by name, and an eval harness that runs the same brief across several frontier models and scores the results against a rule set written by humans who still care about kerning.</p>

  <div class="cta-row">
    <a class="primary" href="https://github.com/ahd/ahd">read the code &nbsp;→ github</a>
    <a href="https://code.ahd.dev/ahd/ahd">forgejo mirror</a>
  </div>

    <h2>Run the eval</h2>
    <div class="h2sub">one invocation · n=10 · diff against the rule set</div>
    <div class="terminal" role="region" aria-label="Terminal command">

<pre><span class="comment"># evaluate a Swiss-editorial brief against three models, ten samples each</span>
<span class="prompt">$</span> <span class="cmd">ahd eval-live swiss-editorial</span> <span class="flag">--brief</span> <span class="arg">briefs/landing.yml</span> <span class="flag">--models</span> <span class="arg">&lt;specs&gt;</span> <span class="flag">--n</span> <span class="arg">10</span></pre>
    </div>

  <section id="ships">
    <h2>What ships</h2>
    <div class="h2sub">in the repository, today, under FSL-1.1-Apache-2.0</div>
    <ul class="manifest">
      <li><span class="idx">01</span><span class="name">Brief compiler</span><span class="tag">stable</span>
        <span class="note">YAML briefs → typed constraint graph; deterministic prompt assembly.</span></li>
      <li><span class="idx">02</span><span class="name">28-rule linter</span><span class="tag">stable</span>
        <span class="note">Each rule named, cited, and refusable. No score without a reason.</span></li>
      <li><span class="idx">03</span><span class="name">Eval harness</span><span class="tag">stable</span>
        <span class="note">Run N samples across M models, diff outputs, produce a rubric report.</span></li>
      <li><span class="idx">04</span><span class="name">Vision-critic scaffold</span><span class="tag">scaffold</span>
        <span class="note">The plumbing, the contract, the fixtures. Bring your own multimodal model.</span></li>
      <li><span class="idx">05</span><span class="name">MCP server</span><span class="tag">stable</span>
        <span class="note">Exposes compiler, linter, and harness over Model Context Protocol.</span></li>
      <li><span class="idx">06</span><span class="name">Editor plugins</span><span class="tag">bundled</span>
        <span class="note">VS Code and Zed integrations, shipped in-tree.</span></li>
      <li><span class="idx">07</span><span class="name">Eight tokens</span><span class="tag">CC-BY-4.0</span>
        <span class="note">A minimal, opinionated starter set. Spacing, type, ink, rule. Nothing iridescent.</span></li>
    </ul>
  </section>
