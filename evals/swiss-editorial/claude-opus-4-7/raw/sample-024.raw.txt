<h1>A design framework for the <em>post-slop</em> web.</h1>

<p class="lede">You have opinions about AI-generated sites already. AHD is not here to change them. It is here to make them reproducible: a brief compiler, a 28-rule linter, and a live eval harness that scores n generations against an editorial rubric you can read and argue with.</p>

<p>The working assumption is that the pattern — hero stack, three cards, gradient heading, logo strip — is not a style choice. It is the shape a model outputs when it is given no constraints. AHD supplies the constraints, then grades what comes out the other side.</p>

<h2>The eval, in one line <span class="mark">› terminal</span></h2>
<div class="term" aria-label="bash command">
  <div class="bar"><span>bash</span><span>ahd ≥ 0.4</span></div>
<pre><span class="cm"># run ten generations against the swiss-editorial rubric</span>
<span class="p">$</span> ahd eval-live swiss-editorial <span class="fl">--brief</span> briefs/landing.yml <span class="fl">--models</span> &lt;specs&gt; <span class="fl">--n</span> 10</pre>
</div>
<p class="caption">Emits a JSON report plus an HTML diff grid. Rubric is a YAML file you can fork.</p>
