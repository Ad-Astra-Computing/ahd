  <h1>Artificial Human Design.<br><em>A framework, not a lecture.</em></h1>
  <p class="lede">You have already seen the slop. Generated sites that all look like the same three Figma kits laundered through a diffusion model. AHD treats that as a measurable regression, not a vibe.</p>
  <p class="sub">It compiles a brief, lints the output against 28 rules drawn from editorial typography, and grades candidate generations with a vision critic running against a reference screenshot. The command below is the thing, not a demo of the thing.</p>

  <div class="cta-row">
    <a class="read-code" href="https://github.com/ahd/ahd">Read the code on GitHub <span class="arrow">→</span></a>
    <a class="mirror" href="https://code.ahd.dev/ahd/ahd">forgejo mirror</a>
  </div>

  <section id="thesis">
    <h2>The thesis, short</h2>
    <div class="thesis">
      <p>Generated layouts regress toward a mean. The mean is soft, centred, safe, and identical across vendors. Designers recognise it on sight; engineers recognise it in the DOM.</p>
      <p>A framework that takes this seriously must (a) refuse to treat "it renders" as success, (b) express taste as rules a machine can check, and (c) let humans edit the rules. AHD is that framework, with a harness underneath.</p>
    </div>
  </section>

  <section id="eval">
    <h2>Run the live eval</h2>
    <p>Ten candidate generations, Swiss editorial brief, linted, vision-critiqued, ranked. Writes a report to <span class="kw">./runs/</span>.</p>
    <div class="terminal" role="region" aria-label="Terminal command">
      <div class="bar"><span>terminal</span><span class="lang">bash</span></div>

    </div>
