    <h1>A framework for design that <em>refuses to look like slop</em>.</h1>
    <p class="lede">
      You already know the problem. Every landing page from the last month
      looks the same because it was generated from the same taste.
      <span class="thin">AHD is the opposite move: a brief compiler, a linter, and a live eval that
      grades a model's output against a documented editorial tradition before
      any of it reaches a human.</span>
    </p>

    <div class="cta-row">

    <section id="ships">
      <h2>What ships <span class="tag">today · in the repo · no keys required</span></h2>
      <p class="note">Everything in this list runs offline against fixtures. Clone, install, read.</p>
      <ul class="manifest">
        <li><span class="name">brief-compiler</span><span class="desc">YAML → typed constraint graph. The thing models actually read.</span></li>
        <li><span class="name">linter (28 rules)</span><span class="desc">Catches centred hero stacks, gradient AI, emoji bullets, the lot.</span></li>
        <li><span class="name">eval-harness</span><span class="desc">Deterministic scoring against the swiss-editorial rubric. Replayable.</span></li>
        <li><span class="name">vision-critic/scaffold</span><span class="desc">The wiring for screenshot critique. Runs on fixtures today.</span></li>
        <li><span class="name">mcp-server</span><span class="desc">Exposes compiler + linter to any MCP-aware editor or agent.</span></li>
        <li><span class="name">editor-plugins</span><span class="desc">In-tree for VS Code, Zed, Neovim. Built from the same source.</span></li>
        <li><span class="name">tokens (8)</span><span class="desc">ink, paper, rule, accent, muted, term-bg, term-ink, term-dim.</span></li>
      </ul>
    </section>

    <section id="gated">
      <h2>What is gated <span class="tag">not in the box · requires external resources</span></h2>
      <p class="note">Honest about the seams. These depend on things we do not ship for you.</p>
      <ul class="manifest gated">
        <li><span class="name">live frontier-model calls</span><span class="desc">Bring your own API keys. We do not proxy or resell inference.</span></li>
        <li><span class="name">live vision critique</span><span class="desc">Needs a multimodal key plus a working screenshot pipeline (Playwright).</span></li>
        <li><span class="name">editor plugins as npm packages</span><span class="desc">Standalone distributions are not published yet. In-tree works now.</span></li>
        <li><span class="name">additional tokens</span><span class="desc">Beyond the core eight. Expansion packs land as separate CC-BY bundles.</span></li>
      </ul>
    </section>
