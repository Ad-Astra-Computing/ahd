You have already noticed that generated pages rhyme. Same hero stack, same three cards, same purple haze. AHD is the eval harness and toolchain that treats that rhyme as a measurable defect.

Artificial Human Design is an opinionated pipeline — brief → linter → eval → vision critique — for people who want model output held to a rubric instead of a vibe. It is not a generator. It grades generators.

What ships today · in-tree

brief compiler
YAML briefs compiled to a typed spec with constraint and anti-pattern slots.
28-rule linter
Static checks for the defects you can spot without a model: pill-badge hero, purple-to-blue gradient, three equal cards, gradient text on "AI", and 24 more.
eval harness
Runs n generations per brief across declared models, scores against the rubric, writes a deterministic report.
vision-critic scaffold
The adapter, prompt library, and screenshot contract. Swap in any multimodal endpoint.
MCP server
Exposes the compiler, linter, and eval harness to any MCP-aware editor or agent.
editor plugins
VS Code and Zed integrations that surface linter output inline as you write briefs and templates.
eight tokens
The initial AHD design-token set: type scale, measure, rule weight, four neutrals, one accent.

What is gated external · not bundled

live frontier-model calls
You bring the API keys. AHD will not ship a proxy and will not pay the bill.
live vision critique
Requires a multimodal key plus a working screenshot pipeline (Playwright is the reference).
npm packages for plugins
The editor plugins live in-tree today; standalone, versioned npm publishes are gated on a maintainer signing off on release cadence.
additional tokens
Expansions beyond the eight are gated on commissioned artwork and a signed CC-BY contribution.

The split is deliberate. Anything that depends on a third-party cost centre or an unresolved license question is marked gated and kept out of the default install. The default install runs offline against fixtures.
