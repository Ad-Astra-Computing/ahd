A framework, not a lecture A taste harness for machines that have none.

You have spent the last month looking at sites that all came from the same bucket: the centred hero, the pill, the two buttons, the three cards, the gradient word. You already know what is wrong. AHD is the part where someone writes the ruleset down and runs it against the models, out loud, on a schedule.

AHD is a brief compiler, a linter, and an eval harness. It takes a design brief in YAML, compiles it into a verifiable specification, and scores model output against 28 rules that working designers actually argue about. Nothing is hidden behind a login. The rules are readable. The scores are reproducible. The disagreements are the point.

One-liner, live eval

~/ahdbash$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

Runs the swiss-editorial rubric against the brief, ten samples per model, prints per-rule deltas and writes an artifact bundle you can diff across runs. Uses local stubs by default; see What is gated.

What ships TODAY · LOCAL · MIT-TO-TEST

  1. Brief compiler.YAML → specification tree with typed constraints and rule bindings.
  2. 28-rule linter.The argued-over rules, each with a citation, a counterexample, and a severity.
  3. Eval harness.Deterministic fixtures, seeded sampling, artifact bundles, JSON reports.
  4. Vision-critic scaffold.Prompts, graders, and a stubbed screenshot loop — wire up a key to go live.
  5. MCP server.Exposes compiler, linter, and eval to any MCP-speaking editor or agent.
  6. Editor plugins.In-tree plugins for VS Code and Neovim. Read the source, symlink to use.
  7. Eight tokens.A small, honest set: ink, paper, rule, mute, accent, flag, measure, grid.

What is gated REQUIRES · EXTERNAL

  1. Live frontier-model calls.Needs your own API keys. AHD does not resell tokens or proxy credentials.
  2. Live vision critique.Needs a multimodal key and the screenshot pipeline (headless Chromium + capture worker).
  3. Standalone npm packages for the editor plugins.Pending registry publication; in-tree versions work now.
  4. Additional tokens.Extended sets (editorial, interface, data-viz) land as the rubric for each stabilises.
