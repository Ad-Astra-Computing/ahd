A framework for design work that refuses to generate slop.

AHD is a toolchain, not a wrapper. It compiles a brief into a linted spec, runs the same prompt across models, and grades the output against a fixed rubric before a human ever looks at it.

You have already spotted the pattern: centred hero, pill badge, three equal cards, shimmer on the word AI. This page is not here to argue that. It is here to show the eval you can run in a terminal in about ninety seconds.

The problem is not that models cannot draw. The problem is that nobody wrote down what good looks like, in a form a machine can be held against. AHD is that form.

01 — Run the eval

Ten generations, one brief, any set of models. The harness writes a run directory, the linter flags rule violations, the vision-critic scaffold reserves slots for the multimodal pass.

~/projects/landingbash
# one brief, ten samples, whichever models you have keys for
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

exits non-zero if any of the 28 rules fail. wires into CI without ceremony.

What ships

Available today, in the repo

  • 01Brief compilerYAML brief → normalised spec + typed constraints.
  • 0228-rule linterTypographic, spatial, and semantic rules. Fails loud.
  • 03Eval harnessDeterministic runner, seeded, writes a run directory per call.
  • 04Vision-critic scaffoldInterfaces and fixtures. Wires to a key when you bring one.
  • 05MCP serverExposes compiler, linter, and harness to any MCP-aware editor.
  • 06Editor pluginsVS Code and Zed. In-tree, versioned with the core.
  • 07Eight tokensSwiss-editorial set. Type scale, spacing, grid, rule weights.

What is gated

Possible, but not on the main branch

  • aLive frontier-model callsNeeds API keys. Bring your own; the harness does not.
  • bLive vision critiqueNeeds a multimodal key and a screenshot pipeline (Playwright).
  • cStandalone npm packages for editor pluginsCurrently in-tree only. Published artifacts are pending.
  • dAdditional tokensBeyond the eight: editorial-serif, grotesque-grid, dense-data. In progress.
