AHD — Artificial Human Design v0.3 · 2026-04-22 · single page

A framework, not a lecture A working definition of slop, and a harness that measures it.

You have already seen the page. Centred hero, two pill CTAs, a gradient on the word AI, three equal cards, a Trusted-by strip with logos nobody asked to licence. You know what it looks like. You are probably tired of arguing about it.

AHD treats design as a compiled artefact from a written brief, graded by a linter you can read, judged by an eval you can rerun on your laptop. The command below produces a ten-variant Swiss-editorial battery against the same brief that generated this page. It is the only demo on the site because it is the only one that matters.

bash · zsh — ahd ~/ahd 
# run the live eval against ten model configurations
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
# → 10 candidates · 28 lint rules · vision critique (if key present) · scored HTML

Reproducible from a clean clone. No telemetry. No hosted inference.

What ships today

  1. Brief compilerYAML → typed intermediate representation; deterministic.
  2. 28-rule linterStructural, typographic, and rhythm checks. Readable source.
  3. Eval harnessScores N candidates per brief; reproducible seeds; JSON out.
  4. Vision-critic scaffoldRendering pipeline, prompt templates, graders. Bring your own model.
  5. MCP serverExposes compiler, linter, and eval to any compatible client.
  6. Editor pluginsVS Code and Zed. In-repo sources; install from source.
  7. Eight tokensThe canonical set used by this page. Swiss-editorial family.

What is gated external

  1. Live frontier-model callsRequires your own API keys. No keys are bundled or proxied.
  2. Live vision critiqueNeeds a multimodal key and the screenshot pipeline configured.
  3. Standalone npm packages for the editor pluginsPending registry publication; install from source works today.
  4. Additional tokensBeyond the eight shipped; grotesque, slab, and display families planned.
