AHD · Artificial Human Design
v0.3 · 2026-04

An evaluation framework for design that refuses to look like the rest of the feed.

You have already noticed. The rounded-square hero, the pill badge, the three equal feature cards, the purple gradient, the shimmer. That is the baseline. AHD treats it as a regression target.

AHD is a brief compiler, a linter, and an eval harness. It scores generated layouts against a typographic rubric and fails builds that drift toward the median. It does not generate better slop. It makes slop visible and rejects it.

Read the code → github.com/ahd/ahd · forgejo mirror at code.ahd.dev/ahd

01Run the eval

One command. Ten samples per model, scored against the Swiss editorial rubric. Output is a diff against the rubric, not a vibe check.

~/projects/landingbash
# evaluate ten samples per model against briefs/landing.yml
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

02What ships

Everything below is in the repository today. No waitlist, no private beta, no "request access".

brief-compiler
Turns a YAML brief into a constraint set the linter and harness can consume.
linter/28
Twenty-eight rules covering hierarchy, rhythm, contrast, and the known slop signatures.
eval-harness
Runs N samples per model, scores each against the active rubric, writes a report.
vision-critic
Scaffold for screenshot-based critique. Adapter interface, fixtures, golden tests.
mcp-server
Exposes the compiler, linter, and harness to MCP-aware editors and agents.
editor-plugins
In-tree plugins for VS Code, Zed, and Neovim. Vendored, not published.
tokens/8
Eight base tokens: type-scale, measure, leading, rhythm, ink, field, rule, accent.

03What is gated

The repository contains adapters and fixtures for the items below. Running them end-to-end requires external resources we will not pretend to provide.

live-frontier
Live frontier-model calls.Needs your own API keys. Local fixtures ship for offline dev.
live-vision
Live vision critique.Needs a multimodal key and a screenshot pipeline (Playwright recipe included).
npm-plugins
Standalone npm packages for the editor plugins.Pending a stable plugin API; currently only the in-tree build works.
tokens/extra
Additional tokens beyond the base eight.Expansion pack is under design review and is not in this release.
