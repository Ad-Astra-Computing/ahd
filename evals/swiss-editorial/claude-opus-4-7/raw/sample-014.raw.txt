  <div class="meta">v0.4 · 2026-04</div>
  <h1>A framework for sites that don't read as generated.</h1>
  <p class="lede">
    You've already noticed it: the centred hero, the pill badge, the three
    equal cards, the gradient on the word AI. The slop has a shape. AHD treats
    that shape as a measurable defect, not an aesthetic complaint.
  </p>
  <p class="lede">
    The pipeline compiles a written brief into constraints, lints output
    against 28 rules drawn from twenty years of editorial and Swiss design
    practice, and runs an eval harness against frontier models so you can see
    which ones cheat and which ones read the brief. There is a vision critic
    in scaffold form. There is an MCP server and editor plugins so the loop
    runs where you already type.
  </p>

  <section id="ships">
    <h2>// what ships</h2>
    <ul class="ship-list">
      <li><span class="tag">core/01</span><div><div class="item-title">Brief compiler</div><div class="item-note">YAML in, typed constraint graph out. Same brief drives generation, lint, and eval.</div></div></li>
      <li><span class="tag">core/02</span><div><div class="item-title">28-rule linter</div><div class="item-note">Detects centred-hero-with-pill, gradient-on-AI, three-equal-cards, fake-testimonial-shape, and 24 others.</div></div></li>
      <li><span class="tag">core/03</span><div><div class="item-title">Eval harness</div><div class="item-note">Deterministic seeded runs, per-model scoring, diff against a reference brief set.</div></div></li>
      <li><span class="tag">core/04</span><div><div class="item-title">Vision-critic scaffold</div><div class="item-note">Local heuristics today (layout entropy, palette deviation, typographic rhythm). Pluggable backend.</div></div></li>
      <li><span class="tag">core/05</span><div><div class="item-title">MCP server</div><div class="item-note">Exposes the compiler, linter, and harness to any MCP-aware client.</div></div></li>
      <li><span class="tag">core/06</span><div><div class="item-title">Editor plugins</div><div class="item-note">VS Code and Zed extensions, in-tree. Lint on save, eval on demand.</div></div></li>
      <li><span class="tag">core/07</span><div><div class="item-title">Eight tokens</div><div class="item-note">A small, opinionated starter palette and type scale. Not a system. A seed.</div></div></li>
    </ul>
  </section>

  <section id="gated">
    <h2>// what is gated</h2>
    <ul class="gate-list">
      <li><span class="tag">gated</span><div><div class="item-title">Live frontier-model calls</div><div class="item-note">Requires your own API keys. AHD does not proxy or resell tokens.</div></div></li>
      <li><span class="tag">gated</span><div><div class="item-title">Live vision critique</div><div class="item-note">Requires a multimodal key plus the screenshot pipeline (headless Chromium, queue worker).</div></div></li>
