AHD compiles a written brief into constraints a model must respect. It lints the output against twenty-eight rules. It runs an eval harness against real outputs. Then it lets a vision critic tell the model it is wrong.

Read 02:40 One screen. No testimonials. No trusted-by strip. No pricing tier.
§01 — Run the eval

One line. Ten renders. One verdict.

The harness writes ten candidates per model, lints each, and scores them against the brief.

~/ahd bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

[compile]  brief → constraints              ok    42 rules
[lint  ]   28-rule linter                   ok
[render]   10 × model                       ...   streaming
[critic]   vision pass (gated)              skip  needs multimodal key
[score ]   weighted rubric                  →     reports/landing.md
Slop.

The word is not a provocation. It is the failure mode. Purple-to-blue gradients. Three equal cards. Glass tiles. Lucide icons in gradient squares. AHD treats all of it as a lint error.

§02 / What ships

07 items · today
  1. Brief compiler Parses YAML briefs into a typed constraint tree the model and the linter share. Ships
  2. 28-rule linter Static rules over DOM and CSS. Flags forbidden patterns and banned phrases. Ships
  3. Eval harness Runs N renders per model, lints each, and writes a markdown scorecard. Ships
  4. Vision-critic scaffold Screenshot adapter, rubric, critic prompt. Wiring only; key-gated below. Ships
  5. MCP server Exposes compiler, linter and harness over Model Context Protocol. Ships
  6. Editor plugins VS Code and Zed integrations. Inline lint, compile-on-save, brief scaffolds. Ships
  7. Eight tokens swiss-editorial, brutalist-press, mono-technical, editorial-serif, archival-grid, cassette-ui, atelier-soft, kiosk-industrial. Ships

§03 / What is gated

04 items · external
  1. Live frontier-model calls You bring the API keys. AHD never ships a provider credential in the box. Needs keys
  2. Live vision critique Requires a multimodal key and a working screenshot pipeline (Playwright or equivalent). Gated
  3. Standalone npm packages Editor plugins publish from the monorepo. Independent npm releases land with v0.2. Gated
  4. Additional tokens Beyond the first eight. Proposals welcome in the issue tracker; merges require an eval run. Gated
