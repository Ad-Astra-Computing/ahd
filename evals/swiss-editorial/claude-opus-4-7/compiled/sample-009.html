§ 01 / Position
Landing · Web · Single screen

A framework
against
design slop.

You have already seen the sites this month. Pill badge. Twin gradient buttons. Three equal cards. A shimmer on the word AI. AHD is a brief compiler, a linter and an eval harness that treats the pattern as a defect and refuses to emit it.

AHD is a specification, a toolchain and a set of tokens. It assumes you can read code. It assumes you have taste. It does not assume your model does.

§ 05 / Position in one paragraph

The problem is not that a model wrote the page. The problem is that nobody wrote the constraints. AHD writes the constraints.

A brief is a compiled artefact. A token is a contract. A lint failure is a bug, not a suggestion. The eval is the product.
