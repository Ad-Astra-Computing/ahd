Design is
a constraint,
not a prompt.

AHD is a framework for evaluating machine-made interfaces against a written brief. It compiles taste into rules. It runs the rules against the output. It reports what broke and why. It does not lecture about the problem. It measures it.

You have already seen the problem. A brief is the answer.

01 — Observation

The current generation of design tools reward fluency over judgement. The output is coherent at the paragraph level and incoherent at the page level. Every site looks like the same site.

02 — Position

Taste is not a vibe. Taste is a written document with rules, forbidden patterns and required quirks. If you cannot lint it you cannot trust it. If you cannot test it you do not have it.

03 — Method

AHD compiles a brief into a prompt and a test suite. It scores the output against 28 rules. It fails loudly when a model reaches for a gradient or a centred hero. That is the entire pitch.

The one-liner  ·  run an eval against the live token bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10
› compiled brief  : 1 token, 28 rules, 6 required, 14 forbidden
› sampled models  : <specs>  (n=10 each)
› linter          : ok — running…
› vision critic   : gated (set OPENAI_VISION_KEY to enable)
› exit            : 0 when pass-rate ≥ 0.7

EVAL.

Every brief ships with its test. No brief, no release.

What ships today · v0.1.0

07 items
  1. Brief compilerYAML → prompt + machine-readable ruleset. Deterministic.
  2. 28-rule linterStatic checks for forbidden patterns, required quirks and structural hygiene.
  3. Eval harnessn-shot sampling, pass-rate reporting, diff against reference runs.
  4. Vision-critic scaffoldPrompt library and scoring rubric. Runs offline on fixture screenshots.
  5. MCP serverExposes compile, lint and eval as tools to any MCP-aware client.
  6. Editor pluginsIn-tree integrations for VS Code, Zed and Neovim. Source only for now.
  7. Eight tokensswiss-editorial, brutalist-print, monospace-memo, archive-grid, japanese-quiet, bauhaus-poster, terminal-green, newsroom.
