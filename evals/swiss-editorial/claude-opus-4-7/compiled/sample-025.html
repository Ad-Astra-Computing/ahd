Design

You have seen the sites. Rounded-2xl on everything. Purple gradients on the word AI. Three equal feature cards under a centred pill badge. We do not need to argue the problem. AHD is the framework underneath the argument.

A token-first system for evaluating generated interfaces. Brief in. Graded output. Twenty-eight structural rules. No hedges.

01

The diagnosis is boring. The response is a framework.

Generative models collapse toward the median of their training set. The median of web design in 2024 was glassmorphism on purple. The median now is a Lucide icon inside a gradient tile above a rounded card.

Models do not know this is ugly. They know it is likely.

AHD encodes taste as constraint. A brief compiles into a token. A token carries forbidden patterns, a grid, a type scale and a palette. A linter refuses the slop. A vision critic reads the render.

No lecture. A file you can run.

Taste.

The full stop is the only red on this page. It is where the argument ends.

№ 02 / Run

One command. Ten renders. A score.

Point the eval harness at a brief. It runs the named token against the models you specify, renders the output, lints the markup against twenty-eight rules, then asks a vision critic to read the screenshot.

~/ahd — bash eval-live 
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

The manifest.

What ships available

  1. Brief compiler
    YAML brief → compiled prompt, with token and forbidden list merged.
  2. 28-rule linter
    Structural checks against markup, CSS variables and forbidden patterns.
  3. Eval harness
    Batch runs, deterministic seeds, side-by-side diff against baseline.
  4. Vision-critic scaffold
    Pluggable, model-agnostic. Local mock critic included.
  5. MCP server
    Exposes tokens, briefs and the linter to any MCP client.
  6. Editor plugins
    VS Code and Zed source trees in the monorepo.
  7. Eight tokens
    swiss-editorial, brutalist-press, monochrome-terminal, and five more.

What is gated external

  1. Live frontier-model calls
    Needs your API keys. Nothing ships with vendor credentials.
  2. Live vision critique
    Needs a multimodal key and a screenshot pipeline.
  3. Standalone npm packages
    Editor plugins will publish once the public API settles.
  4. Additional tokens
    Eight are in the tree. The catalogue expands through usage.
AHD is a research project on what happens when you give a model taste as a file instead of a vibe. Set in Neue Haas Grotesk on a 12-column grid with a 24px gutter and an 8px baseline.
