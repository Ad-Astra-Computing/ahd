№ 01 / Premise

The slop
is the
— default.

You have already seen the sites. Rounded-2xl everything. Purple to blue. A centred hero with a pill badge and two identical buttons. Three equal cards. A testimonials strip that nobody wrote. AHD treats that output as a regression and writes tests against it.

AHD is a compiler, a linter, an eval harness and a vocabulary. It does not generate pages. It constrains the models that do.

№ 02 / Thesis

Design tokens are not decoration. They are the hypothesis under test. Every rendered page is an experiment. The linter is the null result. The vision-critic is the peer reviewer. You ship when the evidence says so.

№ 03 / Run it

Constraint.

Not a prompt. Not a vibe. A brief compiled into rules a model cannot bluff past. Tokens name what must be true. The linter names what must not. Evaluation decides.

№ 04 / Manifest

What ships
today.

In the repository, under FSL-1.1-Apache-2.0. Runs locally. No account. No telemetry. No waitlist.

01
Brief compiler
YAML in, normalised JSON spec out. Resolves tokens, inlines forbidden lists, validates required elements.
02
28-rule linter
Static checks over rendered HTML and CSS. Catches rounded-2xl, gradient text on AI, three-card rows, centred hero patterns.
03
Eval harness
Runs N generations per brief, scores each against the rule set, emits a ranked receipt with diffs.
04
Vision-critic scaffold
Local harness for visual diff and layout inspection. Pluggable critic; ships with a deterministic baseline.
05
MCP server
Exposes the compiler, linter and eval harness as tools to any MCP-aware agent.
06
Editor plugins
VS Code and Zed extensions. Brief-aware autocomplete. Inline lint. Source available in-tree.
07
Eight tokens
Swiss Editorial, Brutalist Grid, Monospace Dossier, Editorial Serif, Neo-Constructivist, Neutral Gothic, Terminal Green, Risograph Two-Colour.
№ 05 / Manifest

What is
gated.

Not withheld. Not coming soon. Bounded by resources that are not ours to give away. The scaffolding is in the repository. You bring the keys.

01
Live frontier-model calls
Requires API keys for Anthropic, OpenAI, Google. AHD does not bundle credits. Config stubs are in /config.
02
Live vision critique
Requires a multimodal key and a working screenshot pipeline (Playwright headless). The scaffold is usable without it.
03
Editor plugins as npm packages
Source ships in-tree today. Standalone publishes to npm and the VS Code marketplace are queued behind review.
04
Additional tokens
Beyond the initial eight. Each token is a research artefact with its own brief, lint profile and receipts.
