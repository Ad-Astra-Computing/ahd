The web is full of sites that look generated because they were. AHD is a framework for designers and engineers who already know why that is a problem.

You have seen the purple gradient. You have seen the three equal cards. You have seen the rounded-2xl everything. AHD is not an opinion about that; it is a compiler a linter and an eval harness.

00:42

Anti‑slop.

Thesis
Generative models collapse toward the median of their training set. Left alone they produce design that is legible as a style. AHD treats that median as the failure mode and constrains the model against a brief a token and a rubric before a single pixel renders.

Run the eval.
Read the diff.

AHD ships with a brief compiler and an eval harness. Point it at a token and a brief file and it will render N candidates across a set of models, lint each one against 28 rules and return a rubric you can argue with.

bash · eval.sh ● ahd@localhost 
$ ahd eval-live swiss-editorial \
    --brief briefs/landing.yml \
    --models <specs> \
    --n 10

Requires API keys for frontier models. See What is gated.
