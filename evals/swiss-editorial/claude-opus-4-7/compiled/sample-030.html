AHD is a compiler, a linter and an eval harness for visual work made with language models. You already have an opinion about generated sites. This one gives you a tool, not a lecture. One screen. No hedges.

Read the code → git.ahd.tools · forgejo mirror
Why this exists The median AI landing in April 2026 is a centred hero with a pill badge two CTAs three equal feature cards and a purple-to-blue gradient. The problem is legible. The response should be too.
§ 02 Run the eval

Ten generations per model. Linter score plus vision critique. Deterministic brief hash.

bash · ~/ahd eval-live
$ ahd eval-live swiss-editorial \
--brief briefs/landing.yml \
--models <specs> \
--n 10
→ compiling brief · hashing tokens · dispatching 10×|specs|
§ 03 — Position

Generated work should be auditable. AHD encodes taste as rules linters and evals rather than as vibes in a prompt.
