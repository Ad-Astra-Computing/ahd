§ 01   Thesis

Compile the brief. Lint the output. Then argue.

AHD treats a design token as a contract. A brief is compiled to constraints. Generated markup is linted against 28 rules. A vision critic reads the rendered screen and reports on what a text-only linter cannot see. None of this removes the designer. It removes the excuses.

This page is itself an AHD artefact. It was produced from briefs/landing.yml against the swiss-editorial token and passed the linter at commit 8f3c2ae. The vision critic is not included in that pass — see §04.

What ships.

07 modules · today
  1. 01
    Brief compiler
    YAML intent plus token file to a constraint tree the linter can enforce.
    Shipped
  2. 02
    28-rule linter
    Grid, type, colour, radius, spacing, forbidden-pattern and copy checks. Exit codes.

    Shipped
  4. 04
    Vision-critic scaffold
    Renderer, screenshotter, prompt template. Bring your own multimodal key.
    Shipped

    MCP server
    Exposes compile, lint and eval as tools to any MCP-speaking agent.
    Shipped
  6. 06

    VS Code and Zed integrations. Inline rule hints. In-tree source only for now.
    Shipped
