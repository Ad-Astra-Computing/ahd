  </div>

  <div class="manifest">
    <div class="ships">
      <h3>What ships</h3>
      <ol>
        <li><div><b>Brief compiler</b><span>YAML in, authoritative JSON spec out. Normalises tokens, merges required and forbidden.</span></div></li>
        <li><div><b>28-rule linter</b><span>Static checks on output HTML and CSS. Catches centred heroes, rounded-2xl, gradient text on AI.</span></div></li>
        <li><div><b>Eval harness</b><span>Runs <em>n</em> candidates, records pass/fail per rule, keeps the winner, files the rest.</span></div></li>
        <li><div><b>Vision-critic scaffold</b><span>Headless render plus screenshot plus rubric prompt. Local-only until you attach a multimodal key.</span></div></li>
        <li><div><b>MCP server</b><span>Exposes compiler, linter and critic to any MCP-capable editor or agent.</span></div></li>
        <li><div><b>Editor plugins</b><span>Bundled integrations for Zed and Neovim. In-tree, not yet packaged.</span></div></li>
        <li><div><b>Eight tokens</b><span>Swiss Editorial, Brutalist Grid, Archive, Tabloid, Memo, Field Notes, Kiosk, Blueprint.</span></div></li>
      </ol>
    </div>

    <div class="gated">
      <h3>What is gated</h3>
      <ol>
        <li><div><b>Live frontier-model calls</b> <span class="pill">keys</span><span>Requires provider API keys. Offline by default.</span></div></li>
        <li><div><b>Live vision critique</b> <span class="pill">keys</span><span>Needs a multimodal key and the screenshot pipeline wired end to end.</span></div></li>
        <li><div><b>Standalone npm packages</b> <span class="pill">roadmap</span><span>Editor plugins are in-tree. Separate <code style="font-family:ui-monospace,monospace;font-size:13px">@ahd/*</code> publications are pending.</span></div></li>
        <li><div><b>Additional tokens</b> <span class="pill">roadmap</span><span>Beyond the current eight. Commissioned or contributed; licenced as CC-BY-4.0.</span></div></li>
