A framework

You have seen the websites. The same hero. The same blob. The same gradient on the word that was supposed to mean something. AHD is a working set of constraints, linters and evals that treats the slop problem as a measurable defect rather than a vibe.

§ 01

The thesis, in one word.

Read · 40 sec

Slop.

Generated design is not bad because a machine made it. It is bad because nobody told the machine what good looked like. The brief was three bullet points. The reference was the last twelve sites it scraped. The output is the average of an average.

AHD is the opposite procedure. A brief becomes a token. A token becomes a lint rule. A lint rule becomes a failing eval. The model does not get to call something done until the rules say it is done.

§ 02

Run the eval.

One command · ten samples
~/ahd · main bash 
$ ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10█

Compiles the brief, runs ten generations across the model specs you pass in, lints each against the 28 rules, scores them with the vision-critic scaffold, writes a verdict file. Exits non-zero if anything regresses.
