Artificial Human Design

You have seen the generated slop. Structural homogeny, thoughtless component placement and a complete absence of design intent.

AHD treats this as an engineering failure. It replaces manual pixel-pushing with deterministic evaluation routines. Provide a brief, define your model specifications and run the harness to enforce strict layout principles over raw output.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
