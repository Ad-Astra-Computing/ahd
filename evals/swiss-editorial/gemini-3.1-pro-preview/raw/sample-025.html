Artificial Human Design

The standard output of generative models applied to visual design is predictable, structurally weak and aesthetically vacant. You already know this.

AHD is a framework that treats visual design as a deterministic compilation target. Instead of relying on a model's latent space to guess a layout, AHD enforces rigid adherence to discrete and tokenized design systems through a strict pipeline of compilation, linting and automated visual critique.

It is an infrastructure for generating interfaces that survive professional scrutiny.

ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

What ships

  • brief compiler
  • 28-rule linter
  • eval harness
  • vision-critic scaffold
  • MCP server
  • editor plugins
  • eight tokens

What is gated

  • live frontier-model calls (needs API keys)
  • live vision critique (needs multimodal key + screenshot pipeline)
  • standalone npm packages for the editor plugins
  • additional tokens
