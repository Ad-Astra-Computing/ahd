RIGIDITY.

Design generated by machines is a problem. The current output lacks structure. The solution is not better prompts. The solution is rigid constraints.

AHD provides an explicit framework for automated design. It compiles briefs into strict rulesets. It enforces typography, grid and colour space. Slop is rejected. The output meets human standards.

Evaluate live Active
ahd eval-live swiss-editorial --brief briefs/landing.yml --models <specs> --n 10

  • eval harness
  • vision-critic scaffold

What is gated
